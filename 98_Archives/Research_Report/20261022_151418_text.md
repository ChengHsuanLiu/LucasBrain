/【SemiAnalysis｜中板架構回歸：SpaceX 的「Kessel」Vera Rubin NVL72】

日期：2026年10月21日
作者：Tony Chien、Wega Chu、Michael Chen、Myron Xie

【執行摘要】

SpaceX 正在開發客製化的 NVIDIA GPU 伺服器架構，供地面及太空軌道部署使用。

PCB 中板（Midplane）重新回歸，取代線纜模組（Cable Cartridges），這是支援太空軌道部署所需要的設計。

台光電（EMC）是最大受惠者，因為它是採用先進第二代 Q-glass 材料的 M10 等級 CCL「EM-898K4」唯一供應商。

SpaceX 將只向 NVIDIA 購買晶片，並自行負責更多其他零組件的採購。

SpaceX 正在開發客製化 NVIDIA GPU 伺服器架構。目前專案代號為「Kessel」，這是一套 Vera Rubin NVL72 機櫃，將用於 SpaceX 的地面及太空軌道運算部署。

【SpaceX 客製化 NVIDIA 伺服器－Kessel NVL72】

Kessel 採用背對背伺服器配置，一側的運算／交換器／運算托盤排列為 5／4／5，另一側則為 4／5／4，維持與 Oberon 相同的總數，也就是 18 個運算托盤及 9 個交換器托盤。

GPU 透過一塊大型被動式 PCB 中板與交換器連接，而非使用線纜模組。這塊中板夾在前後兩側的托盤之間。

換句話說，Kessel 是縮小版的 Kyber，其 Scale-up 運算域較小，包含 72 個 GPU 封裝。

我們推測，在相同 Scale-up 規模下採用 PCB 中板，是為了適應太空部署需求。

由於火箭發射過程中會出現壓力與溫度變化，因此線纜模組較不適合太空部署。PCB 中板也能提供更好的維修便利性。

【台光電（EMC）是中板架構的最大受惠者】

目前這塊 PCB 中板指定使用最高等級的 CCL 材料 EM-898K4，這是一款採用先進第二代 Q-glass 玻璃纖維布的 M10 等級材料，並且需要 84 層板結構。

台光電是本專案唯一的 CCL 供應商，因為它被認為是最可靠的高階 CCL 供應商，具有既有太空應用經驗，並擁有業界最好的 M10 材料。

相較於 Kyber 採用的 EM-896K3、M9 等級 Q-glass 材料，這款新的 PCB 設計使用了更高階的 CCL。

然而，它所需要的層數明顯少於先前 Kyber 中板規劃的 156 層，因此更容易製造，也更具備擴大量產的可行性。

中板連接器目前仍採用 Amphenol 的 Paladin，但中板設計更偏好 Voronoi 連接器，因為 Voronoi 原本就是針對板對板接觸而設計。

至於冷板（Cold Plate），SpaceX 已向供應商調查一體式冷板設計，類似先前 Kyber 原型機所使用的冷板。

【客製化運算托盤與 NVLink 頻寬】

這款 Vera Rubin SKU 將採用客製化運算托盤與 NVLink 配置。

在運算托盤方面，運算板將採用一體式設計，每塊板上配置：

4 顆 Rubin GPU
2 顆 Vera CPU
4 張 CX-9 NIC
8 個 E1.S

與標準 Vera Rubin NVL72 相比，每顆 Rubin GPU 的 Scale-out 頻寬明顯降低至 800G，而每顆 Rubin GPU 對應的 E1.S 數量則增加一倍。

在 NVLink 方面，Scale-up 運算域的 NVLink 頻寬只有標準配置的一半，因為 SerDes 將以單向傳輸模式（Simplex）運作，而 Rubin 原生支援同時雙向傳輸，並搭配 Rubin 世代的 QM4 交換器。

【NVIDIA 提供晶片，其餘由 SpaceX 自行負責】

另一個有趣的細節是 SpaceX 與 NVIDIA 之間的商業模式。

SpaceX 只向 NVIDIA 購買晶片封裝，包括 Rubin GPU、Vera CPU、NVSwitch ASIC／QM4 及 CX-9，其餘零組件則由 SpaceX 自行直接採購。

這與 NVIDIA 過去向資料中心客戶銷售 L6 運算板的方式有很大不同。過去 NVIDIA 不斷增加要求客戶必須購買的零組件與內容。

這個趨勢現在開始反轉，NVIDIA 正在探索讓終端客戶自行採購 SOCAMM 的可能性。我們上個月已向 Memory Model 訂閱者分享這項資訊。

如果 SpaceX 的這種合作安排持續下去，將代表 NVIDIA 進一步延續給予客戶更多自主權的趨勢。

最後，在採購方面，SpaceX 也希望向中國大陸與台灣以外的供應商採購，如果可行，將優先選擇美國製造的產品。

我們認為 SpaceX 計畫在 11 月前決定是否繼續推進 Kessel 專案，而最關鍵的決策因素將是 PCB 中板的可製造性。

我們也認為，儘管 SpaceX 已宣布計畫在 2027 年增加 10GW 的運算容量，但至今尚未與 ODM 及 OEM 廠商敲定訂單，原因是仍在完成這項設計的最終定案。
