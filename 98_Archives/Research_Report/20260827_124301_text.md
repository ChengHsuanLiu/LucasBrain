l   PTFE應用領域
n   全氟 PCB（all-fluorine PCB）：電氣效能最高，DF 性能可達到小於 0.004（less than 0.004），是目前全球最好的材料。但因為 PTFE 需要超過 300°C 進行加工，需要高溫壓合設備（相較之下，主流材料如 M9 碳氫樹脂僅需 240°C）。推估全氟 PCB 在全球要達到有意義的商業化量產，時間點落在 2028 年，或 2029 年會更合適。
n   混合版本 PCB（hybrid version PCB）：使用 PTFE CCL 壓合碳氫化合物膠片（hydrocarbon prepreg）。其電氣效能略遜於全氟，但優於 M9 或 Q-glass解決方案。其製程溫度為 240°C，可直接使用 PCB 廠現有的量產設備，預估此解決方案在 2027 年底前可能實現（come true），目前正與終端客戶進行一系列驗證。
n   只有以下兩個應用是絕對且必須使用 M10 的，因為傳輸速度需求過高，M9 材料無法接近其效能：
u   主機板/中介板/背板（Kyber MP / backbone / backplane）：此應用因為面積（area）比交換器板大得多，且層數（layer count）也多得多，因此會是 M10 需求量最大的來源
u   下一代交換器板（switch board / switch B）
n   其他特定應用與嘗試：
u   高速傳輸線（high speed cable connector / cable）：確實曾經是一個嘗試點。但因為目前 PTFE 供應量有限（capacity constraint），終端客戶傾向將產能放在更有需要的地方。此外，PCIe 6.0 與主機板等已在設計上大量解決了傳輸問題，這與終端設計高度相關
u   光模塊（optical module / transceiver）：確實已有人開始嘗試將 PTFE 材質使用在光模塊上。由於其電氣效能要求不需達到 M10 等級，台虹有提供一些品質較低（低於 M10 等級）的材料供其使用
l   混合版本（Hybrid version）三大技術痛點（高導入門檻）
n   熱膨脹對位困難：碳氫化合物膠片是熱固性（thermosetting）材料，PTFE CCL 是熱塑性（thermoplastic）材料。兩者在 240°C 壓合時，因熱膨脹係數不同會產生不同的熱膨脹現象，導致層與層之間的對位發生困難。
n   鑽孔難度顯著提高：因結構中包含兩種不同材質，在進行鑽孔（drilling）時的困難度會提高。
n   鍍銅導通挑戰：鑽孔後的電鍍（plating）導通必須同時面臨兩種不同材質，極為考驗 PCB 廠在異質材料（heterogeneous material）工藝與補償調整上的能力

n   配方 Know-how 替代 IP 專利：M10 膜沒有人擁有 IP 專利，因為 M10 實際上是一種配方（recipe），而配方是無法申請 IP 的。台虹的技術壁壘在於身為軟板材料系統廠（FPC system makers），具有自己獨特的生產技術與 know-how
l   為何不用 Q-glass 玻纖（896Q）解決？
n   雖然 Q-glass CCL 表面上的 DF 達 0.0039，略優於台虹第二代 PTFE CCL 的 0.0045，但製成多層板後，玻纖的經緯線交叉節點（junction）會導致訊號漂移，且織物樹脂壓合缺乏連續方向性。而台虹無玻纖 PTFE 方向性佳，電流訊號損耗遠低於 Q-glass，且層數越多此優勢越明顯，因此客戶仍堅持使用無玻纖 PTFE
l   為了克服形變並實現多層板量產，其解決途徑包含以下兩大要素之結合
n   材料端（台虹）：透過修改配方（modify recipe），在其中加入填料（add some fillers），以大幅提升結構強度
n   製造端（PCB廠）：**調整其生產製造參數（adjust manufacturing parameters）**以增強整體結構強度。在台虹改質材料與 PCB 廠製程工藝雙重提升下，目前已可做出多層板，且品質各方面取得不錯進展，讓終端客戶看到希望並持續積極採用
