/6/25南亞電路板（Nanya PCB）法人說明會完整會議紀要

一、會議基本信息

會議主題：高階IC載板（ABF/BT）市場、經營業績、擴產規劃、上下游供需交流
參會方：南亞電路板管理層、機構投資客戶
核心背景：AI算力、1.6T高速交換機、存儲芯片拉動高端載板全面緊缺，公司產能滿載，產品持續漲價，上游原材料、設備供給長期受限，同步披露大額高階載板擴產計劃。

二、當前營運概況（Q1、Q2經營數據）

（一）產品營收結構佔比

1. ABF載板：營收佔比55%~60%，AI服務器、GPU、高速交換機核心載體；

2. BT載板：營收佔比30%~35%，配套GPT存儲芯片、內存；

3. 傳統PCB硬板：營收佔比10%~15%，佔比持續萎縮，下半年有望降至10%以內。

（二）產能稼動情況

除普通PCB產線外，ABF、BT IC載板自去年Q4起全線滿載，產能成為公司短期營收增長硬性天花板。

（三）Q2業績表現

1. 營收端：受益工作日恢復、高端產品結構優化、產品均價上調，Q2環比中高雙位數增長；管理層指引Q3營收維持中高雙位數環比增速。

2. 毛利率改善：

◦ Q2毛利率較2024年Q4提升5個百分點以上；

◦ BT載板毛利率升至高十位數區間；ABF載板毛利率位於20%中段~20%高位；二者毛利率差距8個百分點以上；

◦ 下半年毛利率提升幅度將持續放大，呈現加速上行趨勢。

3. 需求驅動來源
① 核心增量：高階交換機，2026下半年1.6T交換機載板量產，單款產品ASP較前代提升一倍以上；
② 服務器產品線：Server A6、AI GPU載板出貨持續放量；
③ 存儲BT載板：內存進入超級上行週期，DDR5需求旺盛，疊加HBM產能排擠，普通存儲載板需求同步走強。

（四）全年盈利預期

1. 2026全年EPS低於2022年；核心拖累因素：上游原材料持續大幅漲價、現有產能已無增量空間；

2. 中長期目標：2027年毛利率、整體獲利挑戰並超越2022年歷史高點（2022年BT毛利率峰值接近30%，ABF歷史毛利率峰值接近60%）。

三、上游原材料：全品類緊缺，供給缺口長期無法緩解

1. 緊缺原材料清單

T Glass高端玻纖布、銅箔、鑽針、油墨、ABF增層膜、PP半固化片全線供不應求，價格持續上行。

2. 核心瓶頸：T Glass電子布

1. 日本主力供應商擴產週期極長：2025年宣佈擴產，耐火磚交期23個月，新窯爐產能2027年底前無法量產；

2. 其他替代廠商僅能採用坩堝工藝，產出低、穩定性差，名義供給量無法轉化為實際有效產能；

3. 行業判斷：2030年前日系原廠（一供）供給佔比遠高於二供、三供，T Glass缺口長期存在。

3. 公司降本對衝方案

1. 推動客戶採用E Glass替代T Glass，同步推行雙線設計；

2. 開發混合基材方案（50% T Glass+50%普通玻纖），降低高端玻纖消耗；

3. 持續開發多元化原材料供應商。

4. 價格傳導機制與漲價幅度

1. 調價模式：按月/兩月與客戶協商漲價，彈性調價轉嫁原材料成本；

2. BT載板：綜合季度漲幅20%~30%，小眾低量訂單極端漲幅可達70%；自2026 Q1起持續漲價；BT制程每一層增層均需同步電鍍，耗材消耗顯著高於ABF，成本壓力更大；

3. ABF載板：漲價幅度溫和，綜合季度漲幅約10%；

4. 成本傳導後仍存在超額利潤空間，毛利率持續擴張。

四、產能現狀、廠區佈局與擴產規劃

（一）現有產能規模

1. ABF載板：名義月產能5000萬顆（按傳統小尺寸CPU測算，當前AI超大尺寸載板實際有效產能大幅縮水）；

2. BT載板：月產能55~60萬平方英尺。

（二）現有廠區運營情況

1. 景興廠：產線升級基本完成，主力生產大尺寸高端載板；僅保留少量產能生產中小尺寸消費類PCB；

2. 樹林廠：稼動率滿載，客戶結構多元；除美系大客戶H外，覆蓋大量數據中心客戶；

3. 崑山ABF廠區：當前稼動率偏低，核心制約為地緣因素；客戶出於供應鏈分散訴求，計劃2027年加大崑山投片量，預計明年崑山稼動率直接翻倍；行業供不應求背景下，無需主動降價爭取訂單。

（三）全新擴產規劃（資本支出創歷史新高）

1. 產品定位：聚焦210×210超大尺寸、26層以上高階有機載板，匹配CoWoS先進封裝、AI高端算力芯片；

2. 產線標準：百級無塵車間、全新世代專用設備，單廠資本開支規模歷史最高；

3. 投產時間：2028年無新增產能產出，最快2029年實現量產；

4. 商務策略：不與客戶簽訂長期鎖價LTA協議，保留定價、產品規格自主權，掌握市場議價主導權；

5. 產出特徵：產品尺寸規格極大，顆數增量看起來有限，但單塊產值、價值量極高。

（四）全行業供給長期約束（2027-2028年雙重緊缺）

1. 核心設備交期超長：激光鑽孔機、機械鑽等關鍵設備交期20~44周，全行業集中擴產導致設備供給嚴重不足；

2. 廠房硬性限制：高端IC載板要求單層完整產線，多層廠房垂直轉運會損傷良率，大面積單層廠房稀缺；

3. 供給增速不及市場預期：市場預估行業年供給增長10%，南亞內部評估僅6%左右；

4. 2027~2028年行業將同時面臨原材料短缺+高端載板產能不足雙重缺口。

五、客戶結構與下游應用需求

1. 核心客戶分類

1. 美系客戶：網通、PC、手機頭部廠商；大客戶H今年景氣偏弱，營收佔比下滑，但所有大客戶均同步執行漲價；大客戶整體營收佔比仍維持高位；

2. AI算力客戶：除頭部英偉達系客戶外，絕大多數AI廠商均在對接26層以上超大尺寸載板開發，CoWoS為行業確定技術路線；

3. 服務器芯片：美系通用Server CPU訂單較少；非美系GPU、Arm架構AI服務器CPU合作推進順利；

4. TPU相關ABF：僅供應前代存量產品，營收佔比約10%，非公司核心業務；

5. 財報客戶說明：年報披露前三大客戶包含封裝廠，終端參考價值低，真實核心需求方為芯片設計公司。

2. 高景氣下游賽道

1. BT載板第一需求：GPT大模型配套存儲芯片；

2. ABF核心增量：1.6T高速交換機、AI服務器GPU、CoWoS先進封裝；

3. 存儲行業：DDR5需求持續上行，內存超級週期尚未結束。

六、行業競爭格局與替代技術判斷

1. 同業事件：同業3037傳出退出BT載板市場，將進一步加劇BT供需緊張，價格上漲週期拉長；

2. 中長期替代基板（玻璃基板Glass Core、陶瓷基板）：工藝痛點較多，仍處於早期研發階段；未來3年內有機ABF/BT載板仍是市場主流，不會出現大規模替代；

3. 本輪漲價週期類比2020年底-2021年行情：產能全面滿載下，盈利提升核心依靠產品調價，毛利率進入結構性持續上行通道。

七、問答環節核心要點匯總

1. 毛利率節奏：下半年毛利率環比提升幅度大於Q2，全年毛利率同比提升幅度有望超10個百分點；2026年難以觸及2022年盈利高點，2027年有望達標；

2. BT載板供需：全年稼動無鬆動，供需缺口持續擴大，季度20%-30%漲價趨勢延續；2026年內BT毛利率有望重回30%區間；

3. ABF載板：漲價幅度溫和，當前毛利率20%+，歷史50%+的毛利率峰值預計2027年才能實現；

4. 中長期供需判斷：2027年前T Glass原料供給無解，2029年前高端新增產能有限；AI行業仍處於發展早期，算力需求增長週期較長，本輪缺料、缺產能週期比2021年更長、矛盾更突出；

5. 擴產風險提示：同業集體激進擴產，但設備、廠房落地存在較大不確定性，市場普遍高估短期供給增量。

八、管理層總結

1. 短期核心矛盾：2027年前高端玻纖原料緊缺，2029年前新增高階載板產能有限，2027-2028年行業將同時缺料、缺產能，供需缺口持續放大，產品漲價具備持續性；

2. 技術路線判斷：玻璃、陶瓷基板短期無法量產，有機載板未來3年仍是行業主流；上游材料廠商擴產節奏緩慢，供給約束短期無解；

3. 行業週期判斷：本輪緊缺週期複雜度、持續時間均超過上一輪，產能排擠效應持續存在，公司將持續把握AI基礎設施相關訂單，等待2029年新產能釋放兌現業績彈性。
