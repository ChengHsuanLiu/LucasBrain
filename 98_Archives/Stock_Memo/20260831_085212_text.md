/📌 MLCC｜庫存探底、漲價由AI高階料向通用料擴散

■ 漲價範圍正在擴大

* 過去漲價主要集中在 AI Server高階MLCC。
* 近期開始擴散到與AI共用的通用型MLCC。
* DDR、消費性電子相關料號過去仍處於去庫存，但近期跌價趨勢已開始趨緩。
* 以國巨來看，5–7月幾乎每月都有調漲價格。
* 8月部分料號再出現 10%以上漲幅。
* 漲價規格主要集中在 0201、0402以上、X5R以上等產品。

➡️ 重要訊號：MLCC漲價已不再只侷限AI最高階應用，開始往較通用、甚至偏消費型應用擴散。

■ 2027供需可能進一步吃緊

* 全球主要MLCC廠商目前擴產仍相對克制，約維持**每年10–15%**的產能增幅。
* 相較AI Server、資料中心帶來的需求增長，供給增速有限。
* 因此分析師預期 2027年MLCC供需將比2026年更緊俏。
* 被動元件首選仍為 國巨、禾伸堂。

⸻

📌 禾伸堂｜AI Server PSU高壓大容量MLCC進入量價齊揚

禾伸堂目前AI Server主要產品為：

PSU使用的大尺寸、高容值、高耐壓MLCC。

這類產品規格與一般消費型MLCC差異大，也是禾伸堂目前最重要的AI成長來源之一。

■ 產能／出貨：2027年底有望達2025年的3倍以上

今年持續增加相關設備，約新增 30–40台。

接下來擴產節奏預計分階段進行：

* 今年下半年持續擴充
* 農曆年後再有一波產能優化／擴充
* 預估2027年底，以顆數計算的相關產品產出將達2025年的3倍以上

➡️ AI Server MLCC不是只有短期拉貨，而是公司正在按照中長期需求持續擴產。

■ ASP：3Q末開始談2027年價格

高耐壓、高容值產品製程難度更高，同樣尺寸下若要同時提高耐壓與容值，ASP會明顯增加。

因此：

預計3Q末開始與客戶洽談價格，主要反映在2027年ASP。

也就是2027年除了出貨量增加之外，還有ASP上升的可能。

因此分析師預期 2027年禾伸堂CSP相關營收占比會進一步提高。

⸻

■ 市場傳言：高階產能不夠，改用低壓MLCC替代？

分析師認為機率不高。

原因在於若改用較低耐壓的MLCC，就需要透過更多顆元件串聯來承受高電壓，但串聯後有效電容量下降，因此必須：

低耐壓 → 串聯顆數增加 → MLCC使用量增加 → 占用更多PSU板上空間

而AI Server PSU本身空間就非常有限。

因此對電源廠而言，較合理的方向仍是：

使用更高容值＋更高耐壓的MLCC，而不是大量低規MLCC堆疊。

尤其未來往更高功率／高壓電源架構發展後，這個趨勢會更加明顯。

不排除部分廠商短期因高階料不足，以低規產品暫時補缺口，但主要客戶應不太會採取這種方案。

⸻

💰 禾伸堂｜獲利有上修空間

禾伸堂6、7月已公告自結數字，無論：

* EPS
* Margin

均優於分析師原先預期。

原先預估2026 EPS約 13元左右，目前認為：

2026 EPS有機會達14–15元以上。

此外，高階MLCC Margin表現、匯率影響等，也都比原先模型假設更好。

⭐ 投資結論

MLCC產業： AI高階料短缺／漲價 → 通用型MLCC開始跟漲 → 消費型產品跌價趨緩 → 主要廠商年擴產僅10–15% → 2027供需有望進一步收緊。

禾伸堂： AI Server PSU高耐壓／高容值MLCC → 2027年底產量較2025年3倍以上＋3Q末啟動2027價格談判＋高階產品組合提升 → 2027具備量價齊揚邏輯。

➡️ 被動元件維持正向，首選國巨、禾伸堂；禾伸堂維持「增加持股」，且2026 EPS有機會由原估約13元上修至14–15元以上。
