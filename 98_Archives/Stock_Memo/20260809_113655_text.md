⭐️即時資訊_營收公告—緯穎 (6669 TT)

2026/08/07

💎訊息內容

緯穎 (6669 TT) 公布2Q26 EPS為80.43元，季增6%，年增23%，大致符合凱基預估，略優於市場共識，1H26 EPS達156.38元，年增33%。公司同時公布7月營收1,176.85億元，月增5.7%，年增39%。

💎結論

1.  緯穎2Q26毛利率9.3 %，略優於預期，營利率7.3%，大致符合凱基預期，毛利率季增主要反應公司會計政策改採「代採購模式」，排除通用伺服器中的記憶體成本計入營收中，加上產品組合優化，通用型伺服器營收佔比持續提升至約70 %，因此帶動毛利率擴張。2Q26費用較為提升，主因為下半年新專案研發開發費用較高所致。公司1H26 EPS達156.38元，年增32.6%。

2.  公司於董事會通過銀行聯貸通過辦理總金額達15億美元（約合新台幣487億元）的三年期銀行聯合授信案，資金用途為充實中期營運週轉金及長期股權投資資金需求，將配合公司在台灣與美國等地的業務與產能擴張布局。公司同時也公告，預計2H26資本支出達9.42億美元（約台幣300億元），加上1H26資本支出119億元，預計2026年資本支出達約420億元，明顯高於2025年之137億元，亦高於我們之預期。

3.  緯穎同時公布7月營收1,176.85億元，月增5.7%，年增39%。此營收達成3Q26營收預估 (季增35% ) 之31%。我們預期儘管3Q26通用型伺服器營收將季減，AI伺服器營收佔比可望突破50%，並在4Q26進一步擴張，動能來自GPU AI伺服器 (含出貨Oracle (美) 與Meta (美) 的VR200與Helios MI455開始挹注營收) 。

4.  管理層認為GPU與ASIC AI伺服器將是2H26-2027年的營收成長主力。凱基預期2027 年Trainium晶片出貨量年增30-40%、且T3 Max液冷式機櫃出貨量提升，緯穎將持續受惠T3營收成長，Amazon Web Services (AWS，美) 將持續為最大客戶。此外，2027年Helios AI伺服器機櫃出貨量可望達4,000-5,000櫃，將大幅推升Meta營收貢獻。除上述專案與客戶外，明年VR系列伺服器出貨量亦將成長。上述正向展望將帶動2027年營收加速成長。

5.  凱基預估2026年每股盈餘370.69元(年增35)%，2027年每股盈餘566.42元 (年增53%)，我們維持緯穎「增加持股」評等，並將目標價由6,475元上修至7,750元，基於2026-27年平均完全稀釋每股盈餘的17倍。
