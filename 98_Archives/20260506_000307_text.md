/# 一、先講結論（給你抓感覺）

👉 **記憶體好轉 → wafer好轉**

* 最快：約 **3–6 個月**
* 常見：約 **6–9 個月**
* 最慢：約 **9–12 個月**

👉 為什麼會有這個 lag？
因為中間卡了兩件事：

1. **庫存去化**
2. **wafer 合約機制**

---

# 二、完整傳導鏈（非常重要）

我們把整條鏈攤開👇

### Step 1️⃣ 記憶體價格先動（最前端）

* DRAM / NAND spot price 上漲
* 例如：Micron Technology、Samsung Electronics開始漲價

👉 這時候：
❌ 還不會立刻拉 wafer

---

### Step 2️⃣ 庫存去化（最大 delay 來源）

記憶體廠通常會：

* 先用「庫存 wafer」
* 或降低 wafer input

👉 所以：
📉 wafer 訂單還是低迷

⏱️ 時間：**1–2 季（3–6 個月）**

---

### Step 3️⃣ 利用率回升（關鍵轉折）

當：

* 庫存降到健康水位
* ASP 持續上升

👉 memory 廠開始：

* 提高 fab utilization
* 增加 wafer start

👉 這時候：
👉 wafer demand 開始「明顯回來」

---

### Step 4️⃣ Wafer 廠反應（再延遲一次）

像：

* Shin-Etsu Chemical
* SUMCO
* GlobalWafers

這些 wafer 廠：

👉 通常是：

* 長約（LTA）
* 或季度調整

👉 所以：
📌 不會立刻反映

⏱️ 再 lag：**1–2 季**

---

# 三、為什麼 lag 會這麼長（核心三原因）

## 1️⃣ Memory 是「用庫存先反應」

記憶體廠有：

* wafer inventory
* die inventory

👉 景氣剛好時：
👉 先用庫存賺價差

---

## 2️⃣ Wafer 是「長約產業」

不像 memory spot market

👉 wafer 特性：

* 供應商集中（寡占）
* 客戶簽長約

👉 所以：
❌ 不會即時變動

---

## 3️⃣ Fab 利用率 ≠ 立刻增加 wafer

記憶體廠會先：

* 拉 utilization
* 再增加 wafer input

👉 這中間又一段 lag

---

# 四、用時間軸幫你看（最清楚）

```
T0：Memory 價格上漲（底部）
↓
T+3M：庫存下降
↓
T+6M：開始增加 wafer start
↓
T+9M：wafer 廠出貨明顯成長
```

👉 所以你看到：
👉 **wafer 永遠比 memory 晚一拍**

---

# 五、歷史經驗（很重要）

## 📉 2022–2023 下行

* Memory 先崩
* Wafer 約 **6–9 個月後才崩**

## 📈 2024–2025 AI 復甦

* HBM / DRAM 先拉
* Wafer 在 **2024 下半年才明顯回升**

---

# 六、但有一個例外（你要注意）

👉 **AI / HBM 週期 = lag 縮短**

原因：

* 幾乎沒有庫存
* 需求確定性高
* 擴產是「預先規劃」

👉 所以：
📌 lag 可能縮到：
👉 **3–6 個月**

---

# 七、投資上怎麼用（重點）

你可以這樣抓 timing👇

### 當你看到：

* DRAM contract price 連續上漲
* 庫存週轉 < 90 天
* memory capex 回升

👉 下一步：
👉 **開始布局 wafer 廠**

---
