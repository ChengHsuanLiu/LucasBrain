【MLCC】
1. 一線供應商已開始削減對 iPhone 和三星手機的供貨，上半年只有二線手機的 MLCC 供應被砍，現在嚴重到一線也受壓。
2. 村田 6 月 MLCC 接單接近 1,550 億日圓，年化約 1.8-1.9 兆，相對今年 MLCC 營收指引僅 1.1 兆。7 月接單村田接近翻倍、太陽誘電 +150%。
3. 7 月數字比平均更高，momentum 還在往上，但一定有非 AI 資料中心的客戶因為擔心要不到貨或漲價把訂單往前拉。
4. 今年通路存貨看起來還 OK。村田指引 AI MLCC 成長 150%、非 AI 部分~13%，非 AI 過去幾年數字很差，正常化後 10%-15% 不是需要擔心的出貨水準。
5. NVIDIA 過去偏好 22µF 這種便宜料，但發現推不動新一代 GPU，決定直接跳到 47µF 與 100µF，供應商因此集中在這幾個料號大量生產，資料中心 MLCC 的生產力和產品組合都明顯改善。
6. 前兩三週蘋果去村田要產能並請它擴產，因太陽誘電、三星電機、京瓷都告知蘋果要降低供貨量。村田因為跟蘋果往來久、是最大供應商也是最大客戶，回應會替蘋果擴產做 capacity shift。沒聽說簽 LTA 或調價，推測村田會拿這個換 RF 那邊的市占，它在 front-end module、filter、PA 對蘋果的份額比較弱。
7. 村田下個月要砍中國手機 allocation，今年第二次，第一次砍約 10%，這次聽說再砍 20%，請客戶去找台灣或中國其他供應商。三星電機也已告知 Samsung Mobile 去外面找供應商。
8. 村田公開說沒有意願漲價，真正原因是極度在意其他產品線的市占率。但只要台灣或中國的公司開始漲，村田一定會跟進。
9. ASP 每漲 1%，太陽誘電 OP 增加約 8%、村田約 4%、TDK 只有 0.5%，TDK 敏感度低是因為最大的事業部是電池。
10. TDP 往上走，電流 delta 改變就要更多電容支撐電源。TPU V8 的 TDP 還低於 1,000W，V9（2028）會到 4,000-5,000W，跟 Feynman 差不多；V10（2029 ）可能接近 10,000W。過去認知 TPU 的 TDP 遠低於 GPU，現在開始追上來。

【ABF】
1. 原本認為大廠很難加價，事實證明是錯的。實際加價對象是 Intel，因為 Intel 的 ABF 載板獲利比 NVIDIA、AMD 那邊低，去年加價幅度蠻大，目的是改善 Intel 這塊的 margin。
2. Ibiden 今年初宣布的 5,000 億日圓計畫裡，2,000 億給 Infinity、3,000 億給 NVIDIA 在大野廠擴建，完全沒有包含 Intel 和 AMD。年底前應該會宣布下一波。
3. 這麼早宣布是因為建廠週期拉長，過去從動土到出貨要三年，現在日本缺工需要四年，等於現在動土、產出是 2030 年的事。
4. 下一波若宣布隔壁再建新廠給 Infinity 用，代表 Infinity 的使用範圍不會停在 V9、可能往後延伸，是未來幾個月的觀察點。
5. 業界宣布順序有慣例，Ibiden 先跑，接著 AT&S 發正式新聞稿，台灣廠商用其他方式宣布。
6. Server CPU 是 ABF 最大終端，需求約 20 億美元、占整體>30%。明年 server CPU 加速成長，但新產能年底才出來而且是給 EMIB，缺貨會持續。
7. 三星電機在內部評估要不要投 EMIB。檯面上的公司都有做 EMIB 的經驗，三星電機以前沒做過，從零直接跳進去門檻比較高，不會那麼快宣布。

【GPU.ASIC 出貨量】
1. 2027 整體出貨量年增五到六成，主要動能是 Google TPU V8 世代出貨翻倍以上，V8 兩個版本從今年下半年量產延續到 2027-2028 上半。
2. 2028 估計偏保守。如果 Broadcom 對 Anthropic 在 2028 部署 10GW 算力的預測是真的，TPU 2028 量產會到 1,300 萬+顆，數字有明顯上修空間。
3. OpenAI 的 Jalapeno roadmap 很積極，第一代 ASIC 估約 150 萬顆，從今年第四季到 2028 上半。執行力要看 OpenAI 和 Broadcom、Synopsys 在機櫃設計與執行的組合。
4. NVIDIA 自己給 FY28 rev growth ~70% 偏保守，我們在它報業績前就估>85%。預期 CoWoS 配額 25/26/27 33.6/73.8/129.5 萬片。
5. Rubin 今年生產量稍超過 200 萬顆，第一波以 1,800W TDP 版本為主，2,300W 版本要到年底或明年第一季。Vera 今年下半約 25 萬顆、2027 約 600 萬顆。

【多機櫃互聯】
1. 單一機櫃往上升級的空間越來越有限，功耗提升太快讓散熱與冷卻管理變複雜，直接影響 GPU/ASIC 的利用率，利用率不高長期會拉高算力成本。
2. 目前比較合理的目標是把每個機櫃的 TDP 控制在 120kW 以內，Google 那邊大概都在 100kW 附近。
3. 模型規模超過 3 兆參數再加上 agentic AI，已經不是單顆晶片或單一機櫃的記憶體裝得下，所以轉向 Superpod，讓幾千顆 GPU/ASIC 共享更大的記憶體密度和頻寬，再靠高速光學互連。
4. Google 2017 TPU v2 就用 Superpod 把 256 顆串起來，2025 年 TPU v6 Ironwood 已經到 9,000 多顆，這個概念不新。
5. OpenAI 第一代 Jalapeno 串聯也超過 2,000 顆，系統算力與記憶體容量頻寬不會低於同業。
6. NVIDIA 的兩個原型，一是 8 個機櫃用 optical scale-up 湊成 576 顆 GPU，二是 Superpod 把 40 個機櫃串起來、約 1,152 顆 GPU+512 顆 Vera CPU，還有 X86、LPU 和 eSSD 儲存機櫃。

【CPU】
1. 今年出貨量年增約 35%，受限於台積電和 Intel 產能不足，2027 年加速到 50%，預期可達 5,000 萬顆，受益的是 AMD 和 Arm 陣營。
2. AMD 已向台積電取得更多 N2、N3 產能，CoWoS 由日月光集團和 Amkor 合力供給。AMD 2027 年 CoWoS 24 萬片、總量可能到 50 到 60 萬片。
3. AMD 2027 會發表三顆更先進的 server CPU，關鍵是 Verano，賣點是每個核心具備最高容量的記憶體密度。SRAM 容量 1.2TB，相較之下 Groq 的 LPU 每顆才 500MB，一顆 Verano 等於兩顆 LPU 加一顆 Vera CPU，做 localized agentic AI 非常有競爭力。
4. NVIDIA 很可能在 2027 下半推出更強版本的 Vera CPU 搭配 Rubin Ultra。Intel 的 Diamond Rapids 如果沒有再延也可以期待。
5. Intel 要維持競爭力必須從 2027 年大幅提高資本支出。以色列新廠 Fab 38 加上美國 52、62 廠，18A 產能 2026 到 2029 年可以增加三倍；14A 從 2027 年開始在 Oregon 的 D1P pilot fab 生產到 2029 年，之後由俄亥俄新廠接手。外部需求最大的客戶應該是 Google 的 TPU。

【記憶體】
1. 海力士給 NVIDIA 的 HBM4 報價折扣高於預期，ASP 還沒定案，但相對三星和美光會有明顯差異。目前看到海力士對 NVDA 的 HBM4 為 24 到 28 美元/GB、比預期低超過 20%，市場價 32 到 36 美元。
2. 主流堆疊會停在 8-Hi 為上限，少數晶片可能 12-Hi，16-Hi 到 2030 年都不太可能。
3. 三星拿下增長最快的客戶，TPU V8i 100%、AMD 70%，海力士仍是 NVIDIA 最大供應商但 ASP 折扣太深，三星 2027 年可能追平或超越海力士成為全球最大 HBM 供應商。
4. GB200 的 fast memory 全由 HBM 和 server DRAM 組成；GB300 開始導入機櫃內 eSSD，每顆 GPU 約 4TB；今年下半年 VR200 翻倍到每顆 8TB。客戶還可以選網路儲存 eSSD 櫃，容量達 1.2PB、每顆 GPU 支援約 16TB，透過 BlueField-4 這顆 DPU 直接串聯 GPU，對 KV cache 上下載幫助很大。
5. Rubin Ultra 規格未定，8-Hi HBM4 的 SKU 被採用機率較高，成本與效能比較平衡。
6. HBM 很可能在 VR300 首次出現容量下降。要支援 agentic AI 的記憶體與 KV cache 需求，唯一選擇是大幅提高機櫃內 eSSD 和網路記憶體 eSSD 的容量，這代表 NAND 已經不是純儲存介面，而是在補快速記憶體的容量和架構。
7. 明年 DRAM bit growth 估約 20%，保守看法 17 到 18%。產能開出來是給 HBM 還是 DDR5 會影響這個數字，如果大部分是 HBM 會更低，因為 HBM4E 的 die loss 更高。

【HBM 降規爭議】
1. 頻寬跟 HBM 的 layer count 和 density 沒有直接關係，取決於 JEDEC 訂的 bus line 規格、每顆 HBM 的速度、 GPU/ASIC 搭配幾個 stack。
2. 16 顆 HBM4、bus line 2048、速度 15Gbps，除以 8 得到 61TB/s；若減少 stacking 高度改用 2-Hi 但增加顆數，頻寬可以超過 100TB/s，比前者高約四成。
3. 實務上做不到，卡在 base die 產能。三星 SF4 的 HBM4 4-Hi ASIC base die 都在 4nm 生產，月產能約 4 萬多片，其中三分之一要供給 NVIDIA 的 LPU SRAM 產品。layer count 從 12-Hi 降到 8-Hi 再到 4-Hi，stacking 數字要增加三倍，三星和台積電都沒有這麼多先進產能，DUV 台數也遠遠不夠。
4. 韓國兩家原廠非常非常反對 4-Hi。坐在辦公室從數字上算 4-Hi 是最好的方案，實際上難以執行。
5. 未來兩三年大部分 HBM stacking 會以 8-Hi 為基本，包括 TPU 和 Vera。AMD 的 MI500、MI600 看起來是 12-Hi，NVIDIA 明確是 8-Hi。

【半導體設備】
1. EUV 需求今年第三次上修，2028 年訂單大幅提升，把 Terafab 算進去整體需求接近 130 台，上一版約 100 到 120 台。主要是台積電大幅上修，海力士和 Intel 也繼續上修。
2. 130 台的需求會讓 ASML 供給出現兩成缺口，2027 年缺口~15%，兩年累計至少 30 到 35 台 Low-NA EUV。未來六個月 ASML 必須再往上提升供給。
3. DUV 2027 不是瓶頸但 2028 可能是。Immersion、Dry 加 KrF 的 2027 訂單約 450 台，ASML 年產能約 600 台，如果 2028 年需求超過 600 台而 ASML 不擴產就會卡住。
4. 疫情後 ASML 的 DUV 出貨量到 2026 都比 2023 低，但如果 2027 預測成真會有明顯成長，尤其 KrF。KrF 是所有晶片製造最基本的機台，若 KrF 在 2028 成長 5% 或更高，合理推論產能擴張會擴散到 3D NAND、成熟邏輯，甚至 power 和 analog。
5. Advantest 的 SoC 測試機從 2025 不到 4,000 台到 2028 超過 1 萬台，三年成長三倍，兩個原因是台積電先進製程擴張很快、chiplet 架構帶動晶圓測試需求。
6. 3D 堆疊若在 2028 成為主流，partial assembly testing（部分組裝測試）會是新一波強勁的成長動能。

【台積電】

1. 2026-28 資本支出可上看 2,500 億美元，明年約 850 億美元。
2. 跟 AMD 聊下來，他們覺得台積電 2027、2028 年給的 N2 產能不夠，尤其 2028 年，GPU 和 CPU 兩邊都要更多。
3. 先進封裝擴張比原先想像快。原本預估 CoWoS 2027 年月產能到 18 萬片就不再增加，現在看起來還會大幅往上，因為高雄 AP8 多建了四座新廠，明年年中機台就會開始運作。
4. Panel 的第一個量產無塵室空間由新竹既有的八吋無塵室提升而來，這部分還沒算進模型。
5. 2028 EPS 已經超過新台幣 200 元，今年大概 100 元多一些，需求沒有太大改變的話三年內 EPS 翻倍。

【網通、CPO、OCS】
1. 目前沒有聽到 NVIDIA 會用 OCS。OCS 串聯的是傳統 module，可以想像成訊號的延長線，在 NVIDIA 所有 networking roadmap 裡都沒看到。
2. NVIDIA 未來三到五年想建立的是 CPO，所有廠商裡 NVIDIA 在 CPO 最積極。路徑是 CPO 先進 Spectrum、Quantum，到 Ultra 進 NVLink，到 Rubin 可能有 OIO。
3. OCS 用量比較大而且確定的還是 Google，下一個也許是 Meta，Meta 比較用在一般資料中心的 spine 層級。
4. 現在 Google 的機櫃是 64 顆一個 rack，接下來可能走到 32 顆一個 rack，因為熱和機械負重的關係。兩個 32 要連在一起也會用 OCS，而且前段一定要先走光，所以 per TPU 的 OCS 用量會增加。

【PCB】
1. 今年大部分是材料 upgrade、process upgrade 比較少，所以 CCL 漲價但 PCB 廠來不及把成本 pass through。明年材料已經到 M8、M9，再往上空間越來越少，反而是製程從 multi-layer 升級到 N+M，這個 process upgrade 的 value 屬於 PCB 廠。
2. CCL 漲價速度變慢之後 PCB 廠就來得及轉嫁，今年下半年應該會明顯看到 PCB 毛利率跳升，明年更明顯。
3. 明年 PCB 短缺的機會很大，因為 process upgrade 之後良率一定會降。加上今年大家 focus 在 CCL、PCB 的 valuation 比較便宜，毛利率跳升幅度應該比 CCL 大。
4. PTFE 是好材料但難加工，很難用在 layout 密度很高的地方，明年最有可能用的還是 Rubin Ultra 的 midplane，因為 midplane 只傳資料不計算、線路複雜度不高，比較容易用 M10 配 PTFE。目前只看到 NVIDIA 要用，製程加工難所以很難成為高階主流。

【QA】
1. Q：如果 Google TPU 的 TDP 是 4,000 到 5,000 瓦，散熱規格如何提升？
A：（George）這一代 Sunfish 不只 TPU 是液冷，OSFP module 也是液冷，這是 module 第一次要液冷，下一階段 switch 也會是液冷。現在一個 tray 放四顆 TPU，走到 TPU V9 時一顆 IC 是兩個 die、尺寸整個變大，一個 cold plate 可能只放兩顆，還會有 cold plate 材料上的改變。

2. Q：ABF 跟 PCB 這邊有什麼 update？
A（George）：先前認為大廠很難加價，事實證明是錯的，對不起。實際加價針對 Intel，因為 Intel 的載板獲利比 NVIDIA、AMD 低。產能方面 Ibiden 今年會有新宣布，接著通常是 AT&S 發正式新聞稿。現在基本上什麼都缺，特別是 server 這塊，因為 Ibiden 那 5,000 億的投資完全沒有包含 Intel 和 AMD。下一波可以注意會不會針對 server CPU 有新產能。Ibiden 還是 Intel 最大的 server substrate 供應商，AMD 那邊過去也是它最大，但 AT&S 去年崛起後一下子變第二大。另外可以注意 EMIB 有沒有新公司加入，聽說三星電機在內部評估。

3. Q：EMIB 目前的良率如何？遇到什麼生產問題？
A（George）：良率聽說還是非常非常不好。最難的是做 TSV 跟 silicon substrate alignment 的時候，瓶頸在這裡。全球可以做這台機器的只有一家獨供公司 Toray Engineering，日本上市公司的子公司，單價一台 300 到 400 萬美金。量產是明年才會發生的事。但他們跟 Intel 有一個協議，不管良率低於 50% 還是 40%，margin 還是非常好，因為 Intel 會用高價收購，良率往上走才要降價還給 Intel。供應商那邊的講法是不管良率在哪裡，獲利都比現在的 margin 更好。

4. Q：DUV 在 2027 年是不是有供給瓶頸？
A：2027 年 Immersion、Dry 加 KrF 的訂單約 450 台、還少於 500 台，ASML 一年產能約 600 台，應付得來。2028 年如果不擴產可能變瓶頸，要繼續觀察客戶下單狀況，超過 600 台就有可能卡住。

5. Q：HBM 後面反而會走 4-Hi 或 8-Hi，對 inference 是不是比較好？是不是更利好 TCB 設備？Hybrid bonding 肯定 delay？
A：不需要 16-Hi 的話對 TCB 有利，但對 layer count 相關的供應商不利，包括 DISCO、TEL。競爭對手一直講 inference 端 HBM 降規，是因為架構傾向把很多 DRAM 串聯起來提高系統記憶體容量和頻寬。（頻寬算式與 base die 產能限制見 HBM 降規爭議段落。

6. Q：HBM 規格降規的趨勢對設備商有什麼潛在影響？
A（Steven）：比較負面的是 Besi 和 DISCO。Besi 主要做 hybrid bonding，沒有 16-Hi 基本上就沒有 Besi 的生意，這個架構還需要一段時間；DISCO 的 grinder 會比較少。比較正面的是 Advantest，海力士的 HBM base die 都在台積電做，base die 不是用 memory tester、可以直接用 V93K，所以 base die stack 越多 V93K 越受惠。另一家受惠的是做 CoWoS 與 HBM stack 機台的設備商。
