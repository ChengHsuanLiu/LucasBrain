/結論先講：這段文字抓對「CPO 會縮短高速電氣路徑」的方向，但把影響範圍嚴重放大了。它主要影響交換器 ASIC 到前面板光模組的高速走線，不能直接推論整台 AI 伺服器的主機板、OAM、UBB、midplane、backplane 都只剩 PCIe Gen5，並全面由 M8／M9 降到 M4。

更接近真實情況的是：價值從部分傳統交換板走線，搬向 CPO 封裝、載板；同時 Vera Rubin 的 cableless 架構又把部分纜線價值搬進 M9 高層數 PCB。對 CCL 是「板件間重分配」，不是全面消失。

## 兩段文字的判定

### i.「CPO 後主機板只剩 PCIe Gen5，CCL 可降到 M4」

這個結論不成立，主要有四個問題：

1. CPO 直接縮短的是交換器 ASIC 到光引擎的高速 SerDes 路徑。Broadcom 的定義也是把光引擎放到 ASIC 旁的共同封裝基板，降低 trace loss；並不是把 GPU、CPU、HBM、NVLink、PCIe 等全部光化。[Broadcom CPO 架構](https://www.broadcom.com/info/optics/cpo)

2. Vera Rubin 目前仍把 scale-up 與 scale-out 分開：

   - NVLink 6 負責機櫃內 GPU scale-up。
   - Spectrum-6 CPO 負責機櫃外 scale-out。
   - NVIDIA 只把 NVLink CPO 列入更遠期 roadmap，並非目前 Rubin NVL72 已全面採用。[NVIDIA Vera Rubin 技術架構](https://developer.nvidia.com/blog/?p=111036)

3. PCIe Gen5 不是單純「低速控制訊號」。PCI-SIG 定義其每 lane 為 32 GT/s，x16／x32 仍是相當高頻寬的資料通道。[PCI-SIG PCIe 5.0](https://pcisig.com/what-bit-rates-does-pcie-50-specification-support-and-how-does-it-compare-prior-pcie-generations)

4. CCL 等級不能只由協定名稱決定，還要看走線長度、層數、連接器、via、串擾、熱可靠度、CAF、板厚及製程良率。因此「只剩 PCIe Gen5＝M4 足夠」沒有足夠工程依據。

### ii.「448G 時 5–10 公分都跑不到，勢必全面走光」

物理趨勢正確，但「全面」過度武斷。

SerDes 提速確實會縮短無 retimer 的電氣傳輸距離，推升 CPO、NPO、optical I/O；但仍可搭配：

- 超短距 electrical interface
- Retimer／redriver
- M9／M10 低損耗 CCL
- Flyover cable
- Co-packaged copper
- 封裝內互連
- 電／光混合架構

Broadcom 現有 CPO 交換器也保留部分 electrical lines，支援 DAC 或傳統可插拔模組，證明量產架構可以混用，不必一次全面光化。

## 到底影響哪些板？

| 板件 | 影響方向 | 判斷 |
|---|---|---|
| OAM | 仍承載 GPU、HBM及 scale-up endpoint | 近期高階化；遠期 optical I/O 才構成風險 |
| UBB | 部分長距互連可能被 midplane 或光互連重構 | 中性偏負，但本身價值池已縮小 |
| 一般主機板 | CPO 直接影響有限 | 小幅負面，不是 CCL 主戰場 |
| Midplane | Cableless 將部分線纜改為高層數 PCB | 2027–2028 明顯正向；遠期 scale-up CPO 是風險 |
| Backplane | 高密度機櫃互連帶動 M9／高層數需求 | 近期正向；遠期留意 optical backplane |
| Switch board | ASIC 到前面板光模組的走線最直接被 CPO 縮短 | 局部負面，但不會整張板降成 M4 |
| 控制／電源板 | 高速 SerDes 不是主要材料價值 | 影響有限 |
| IC 載板 | CPO 封裝直接增加整合難度 | ABF／玻璃核心載板相對受惠 |
| CPO 封裝 | ASIC＋光引擎共同封裝 | 最直接受惠層 |

## 價值影響有多少？

依 Trend Core 引用高盛的 2028E GPU 伺服器 PCB TAM：

| 板件 | 2028E TAM | 占比 |
|---|---:|---:|
| OAM | US$24.168bn | 56.8% |
| UBB | US$0.784bn | 1.8% |
| 主機板 | US$0.116bn | 0.3% |
| Midplane | US$5.787bn | 13.6% |
| Backplane | US$0.900bn | 2.1% |
| Switch board | US$9.010bn | 21.2% |
| 其他 | US$1.803bn | 4.2% |

資料來源：[Trend Core：一台 AI 伺服器有哪幾種板？](https://gooptions.cc/trend-core-research-ai-server-board-full-stack-seven-parts/?utm_source=mcp&utm_medium=research_framework)

可以得到三個重要結論：

- 即使把 UBB 與一般主機板假設成「全部降規」，兩者合計只有 US$0.9bn、占 GPU PCB TAM 約2.1%，不足以破壞整體高階 PCB／CCL 邏輯。
- 交換板占21.2%，是 CPO 最直接的風險池；但 CPO 只縮短其中部分高速 I/O 走線。因此21.2%是「受影響板件的理論上限」，不是可能損失率。
- OAM＋midplane＋backplane合計 US$30.855bn、占72.5%。目前 cableless 與 rack-scale 整合反而推升這部分的面積、層數及材料要求。

Trend Core 的基準甚至假設 Rubin Ultra midplane 採 M9、78層以上，每架兩片價值約 US$225,000。雖然這是高盛供應鏈推估、信心屬中等，但它清楚說明：同一代架構可能同時「CPO 縮短交換器板走線」與「cableless 增加 midplane CCL 價值」。

## 對 CCL 長期投資價值的判斷

### 至2028年：沒有推翻高階 CCL 論述

Trend Core 引用高盛估計，AI 伺服器 CCL TAM：

- 2025：US$2.477bn
- 2028E：US$47.546bn
- 其中 M8：US$9.503bn
- M9以上：US$27.777bn
- M8＋M9以上占2028E TAM約78.4%

短中期的主力仍是 cableless、高層數、HDI升階、ASIC平台擴張，以及 midplane／backplane／switch tray 的材料升級。Spectrum-X CPO量產本身，還不足以推翻這條曲線。

### 2029–2030以後：終值確實要加入 CPO折價

真正需要擔心的不是目前的 scale-out CPO，而是未來出現以下組合：

1. NVIDIA／主要 CSP 正式把 CPO導入 NVLink scale-up或GPU optical I/O。
2. 新平台 BOM顯示 midplane、backplane、OAM的高速 CCL面積或等級實際下降。
3. CCL廠的 M9／M10營收占比、ASP及毛利率同步停止上升。

若三者出現，CCL的價值驅動將從「每一代全面升規」，轉成較局部的高層數、電源完整性、可靠度及特定板件認證。這會影響終值與合理本益比，但仍不代表 CCL消失。

我的最終判斷是：

> CPO 對高階 CCL 是局部替代、整體重分配。2028年前 cableless與AI系統複雜度增加，較可能大於交換板局部降規的負面；2029年後若 scale-up optical I/O落地，才是高階CCL真正需要重新估終值的時間點。
