# 伺服器無電纜化(Cableless)架構轉型

## 🎯 產業投資點評與核心結論 (Summary & Insights)
* **產業 So What？（這為什麼重要）**：
  - NVIDIA 從 Blackwell(GB200/GB300) 轉向 Rubin(NVL72) 世代，運算托盤內部從「高頻內部銅纜（Internal Cables）」全面改為「板對板連接器(B2B)＋超高層 PCB 中介板(Midplane)」，同時記憶體改採 SOCAMM 模組化設計、網路與運算模組解耦（Orchid/Strata）。這個架構轉折讓產值從內部線束組裝廠，轉移到高階 CCL/PCB 材料廠、精密連接器廠與分區液冷零組件廠，是一次明確的供應鏈受益/受害名單重分配。
* **關鍵洞察**：
  - Blackwell 時代的財富密碼是「水（液冷）與線（內部高頻銅纜）」；Rubin 世代轉為「板（超高層 Midplane/高階 CCL）與口（B2B連接器/SOCAMM Socket）」。
  - 組裝時間從 2 小時縮短到 5 分鐘，但門檻不降反升——板對板精密對準與微型水路盲插接頭的公差要求達到航太級，只有具備極高自動化資本支出能力的一線代工廠能跟上，二線 ODM 與一線的技術/資本壁壘被進一步拉開。
  - 對 NVIDIA 與 CSP（微軟、亞馬遜、Google）而言，無電纜設計解決了 Blackwell 時代液冷水路故障頻傳的出貨瓶頸，同時大幅降低資料中心維護成本（MTTR）。

## 🧠 產業深層結構與底層物理 (First Principles)
* **訊號完整性驅動無電纜化**：內部訊號路徑越長，在高頻高速下雜訊與衰減越嚴重。改用中央 PCB Midplane 走線取代電纜，能大幅縮短並穩定訊號路徑，這是先進封裝以外，board-level 訊號完整性的另一個關鍵解法。
* **SOCAMM 模組化重新分配製造價值**：記憶體從主機板直接焊接(On-board SMT)或傳統插槽(SO-DIMM)，改為壓縮觸點的 SOCAMM 模組，把原本屬於代工廠 SMT 打件的加工價值，轉移到模組廠與精密連接器/插槽供應商手中。
* **網路與運算解耦帶動液冷複雜化**：Orchid(網路)與 Strata(運算)模組分離後，熱源被物理分散，液冷系統從單一大水冷板演進為需要更多分流閥(Manifold)、快接頭(QD)與漏液偵測系統的「分區分流液冷」，零組件數量不減反增。

## 🗺️ 產業鏈地圖與廠商財務比對 (Supply Chain & Financials)
### 📈 極端利好：高階 CCL/PCB 與精密連接器
| 產業位置 | 推薦個股 | 主要角色與受惠邏輯 |
| :--- | :--- | :--- |
| 超低損耗 CCL 材料 | `[[6274台燿]]`、`[[6213聯茂]]` | Midplane 層數預計從20幾層飆升至30層以上，須全數採用 Ultra Low Loss 樹脂與高階 CCL(如M8等級)，價量齊揚 |
| 超高層伺服器 PCB(HLC) | `[[2368金像電]]`、`[[3037欣興]]` | 網路與運算解耦(Orchid/Strata)加上巨大 Midplane 板，超高層 PCB 產能消耗加劇，毛利率高 |
| CPU Socket / 精密插槽 | `[[3533嘉澤]]` | 全球 CPU Socket 巨頭，SOCAMM 導入伺服器 CPU 帶來全新高毛利精密 Socket 與壓接技術產品線 |
| 高頻板對板(B2B)連接器 | `[[3526凡甲]]`、`[[3665貿聯]]` | Paladin HD2 等 B2B 連接器全面取代線束；貿聯同時布局高頻板對板連接器與伺服器內部高階插槽，可切入液冷分流控制系統 |
| 分區液冷零組件 | `[[3017奇鋐]]`、`[[3324雙鴻]]` | 分區分流液冷需求增加分流閥、快接頭與漏液偵測系統，液冷系統整合價值不降反升 |

### 📉 極端利空：內部線束與缺乏自動化的二線代工
| 產業位置 | 推薦個股 | 主要角色與受害邏輯 |
| :--- | :--- | :--- |
| 伺服器內部高頻線束 | `[[3665貿聯]]`(內部線束部門)、`[[1439良維]]` | Rubin 運算托盤內部無電纜化，過去靠內部高頻銅纜(如Overpass Cable)的高附加價值合約將歸零 |
| 傳統 SMT 打件廠 | (未具名傳統打件/測試廠) | LPDDR5X 模組化為 SOCAMM 後，不再需要高難度的主機板直接焊接，加工價值被收攏到模組廠 |
| 二線 ODM 代工廠 | `[[2356英業達]]`、`[[3706神達]]` | 組裝時間縮短不代表門檻降低，反而需要投入昂貴的航太級自動化精密對準設備，與一線代工廠(鴻海、廣達)的技術與資本壁壘被進一步拉大 |

## 💼 終端應用與核心客戶 (Applications & Customers)
* **NVIDIA Rubin NVL72 機櫃**：取代 Blackwell(GB200/GB300)世代，是這一整波供應鏈重分配的架構源頭。
* **CSP 雲端服務商**（微軟、亞馬遜、Google）：受惠於無電纜設計降低的資料中心維護成本(MTTR)與更低的營運中斷風險（Orchid/Strata模組可熱插拔更換）。

---

## 📅 產業趨勢與產品迭代時間軸 (Timeline)
* **Blackwell 世代（GB200/GB300）**：內部高頻銅纜複雜，組裝與散熱水路故障頻傳，成為 NVIDIA 出貨瓶頸的主要故障點。
* **Rubin 世代（NVL72）**：運算托盤全面無電纜化(Cableless)，改採 B2B 連接器＋PCB Midplane，記憶體改採 SOCAMM 模組，網路(Orchid)與運算(Strata)模組解耦，組裝時間從 2 小時縮短至 5 分鐘。
