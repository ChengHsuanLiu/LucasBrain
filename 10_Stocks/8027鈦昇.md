## 🏭 產能規劃與爬坡 (Producing Power)
* **廠區配置**：橋頭科學園區今年底將有新營運大樓，燕巢廠具Class 1000無塵室，新大樓亦規劃無塵室；2027年下半產能將擴大(地板面積約現在1.6倍，廠房約1.2倍)，現階段缺的是料與人力(非廠房)。
* **南通廠(中國)**：電漿切割代工已開始小量生產並轉為盈餘貢獻；已通過日本最大MLCC公司驗證，年底交運。
* **產能瓶頸**：料源方面IPC(工業電腦，研華/樺漢等)、台達電driver等零組件缺貨，IPC lead time從1.5個月拉長至3個月，屬CoWoS供應鏈通用瓶頸；機構件則非普遍缺料。
* **玻璃基板(TGV)全流程設備**：雷射改質 → 濕蝕刻(委外合作，非自行開發) → ABF鑽孔 → 電漿擴孔 → ABF移除 → 玻璃切割，最少五道設備，可延伸2-3個附屬設備。
* **技術優勢(雷射改質速度)**：目前產出速度約1,500~2,000孔/秒，主要美系競爭對手(德廠)僅約50~60孔/秒(差距約30-40倍)，開發超過十年、專利光路兩年前完成優化；一片510*515玻璃(約400萬孔)目前不到半小時可完成，孔徑主流80~120um。

* Q 四大設備占比 / A 今年北美營運狀況會維持跟去年差不多但都是動態，今年發展比較好是中國，北美維持去年，中國的半導體需求今年很強。
* Q 在手訂單跟lead time / A 接單狀況今年Q4產能大概快滿，長交期的設備已經看到27Q1。
* Q intel馬來西亞 / A 馬來都是研發跟產品，所以EMIB T擴產還是美國跟越南為主。
* Q 拆解glass我們鈦昇的機台有在哪幾個製程 / A TGV這塊的設備提供第一排TGV雷射改質，原本跟美系客戶發展6年，後面ABF鑽孔是第二個設備，再來是鑽孔後的電漿清蝕刻，後面是比較新的製程，換了玻璃就要ABF移除，移除完還要切割，所以最少五個製程設備，跟板廠客戶已經談到量產架構，會從這五個延伸2~3個附屬設備，所以生態對鈦昇來說是很巨大。
* Q 板廠是哪邊的 / A 台系日系都有，今年底就會開始下單，目前在驗證末段，大量是明年第二季。
* Q TGV還有一些挑戰，覺得提前的原因是客戶的反饋還是我們研發的技術已經過了 / A 今年一月份日本那邊得展會美系客戶已經說做完產品的成品，現在這個逞品哪一家買單還沒定案，所以對產品本身而言美系客戶已經成熟，其他還是有技術門檻，會造成美系客戶會布局其他客戶的授權，他已經可以量產。
* Q PLP跟AOI這邊27年底的營收占比 / A FOPLP是其中一個產品線，個人認為這邊使用量最大在低軌，最近交的還是低軌客戶，其他客戶我們在開發中，整個PLP的占比在我們公司這一兩年還不是主流，比例上可能會回到雷射產品跟TGV這邊；檢測設備發展主要在14A 18A，最近就在談產線的規劃，後面如果有更新再說。
* Q 雷射改質一片玻璃的改質時間 / A 改質時間在我們來說是優勢，開發已經開發十年了，但速度是問題，大家的速度都在一片需要花3~4天，目前產能在30~40倍所以才有量產可能，大家都覺得每個人都可以做，但量產性應該鈦昇是唯一有量產，現在大概不到半小時可以做一片510*515，大概是400萬孔。
* Q ABF切割他是把ABF拿掉 / A 對要把切割道上的ABF拿掉，才能做切割，線路上的ABF還會在。
* Q 美系客戶雷射改質還有其他供應商 / A 他早期用德國供應商，他發展超過十年但產出速度沒突破，五六年前找我們做這件事，到兩年前我們自己開發專利光路才把產出速度提升，第一代產出提升6~7倍，現在走到第三代。
* Q TGV AOI檢測400萬孔大概花多久 / A 大概分兩到三個部分，檢測改質完、蝕刻完成孔、填完孔，所以每個製程後的檢測速度不同，成孔可能速度要在一片幾分鐘，填孔的話目前那塊不容易突破，有人用分層檢查，類似CT斷層，有人用X光去照，時間就會比較久，要看每家設備商的能力。

**會後 QA**：
* Q TGV濕蝕刻是我們出嗎 / A 我們跟蝕刻廠配合，本身是沒有要開發那塊。
* Q 放上載板電漿切割 / A ABF鑽孔之後的電漿是我們，那個其實是擴孔。
* Q 那些設備需求最大 / A 雷射切割跟打印需求最大，這一兩年切割跟打印台灣是OSAT，OS段的訂單外溢，我們在矽品日月光的生意會變多，原本在OSAT的封裝製程電漿的蝕刻設備也會用我們，對我們有幫助。
* Q 訂單預期 / A OSAT大概只會給一年內，intel會給到三年。
* Q YOY / A 今年成長狀態比去年應該保守都有20%。
* Q 發酵的議題 / A 玻璃基板明年開始，但擴廠大的時間會是後年，玻璃基板後段有可能比前段大，這次新的CPO的東西也是要等到後年，因為1.6T明年試產後年量產。
* Q 台系客戶跟日系客戶哪個TGV進度比較快 / A 台系只有`[[3481群創]]`，進度沒有期待的那麼快，美系那邊本來就有我們設備小量產，就是看規模怎麼放大，日系很積極要搶這個市場，日本也是我在跑有感受到。
* Q 2027年有可能看到第二大客戶變成日系 / A 期待。
* Q 雷改有出給面板廠 / A 有出，但付款還有一些條件在，量產哪一家還不確定，比較好的議題是310*310有跟台積合作所以那個議題比較好。
* Q 有出給神山的產品嗎 / A 2020年有出，最近交給他們都是檢測，都是先進製程的，幾乎都是雷射的，最近在談電漿。
* Q 先進封裝還是大比例先進製程小部分 / A 對，今年封裝比較比較高因為中國倍數成長，財報第一季毛利率比較低因為中國比例起來，中國目前沒有玻璃。
* Q 台積還有在驗證的嗎 / A 有兩個先進封裝的大專案在驗，for NV下一代產品，時間點下半年他們內部要成案，雷射跟電漿的。
* Q 橋頭的產能是雷射還是電漿多 / A 雷射比較多。
* Q 美國客戶ABF+玻璃的方案 / A 他自己發展，早期我們成立國內玻璃聯盟因為資訊太封閉，我們只做一站，但我們也不只要賣他，所以才會說把製程串起來，他那一段也在美國作，他有些製程是在實驗室做出來再給當地的設備商作量產機，但回到玻璃基板他們應該不會自己量產，他早期ABF技術開發出來就找ibiden、`[[3037欣興]]`、`[[1303南亞]]`幫他生產，他把專利授權出去而已，玻璃基板也會一樣，他不作板廠這些產品。
* Q 欣興 / A 最積極，但日本更積極是說他們連前段TGV都想做，`[[3037欣興]]`或是其他人都是拿別人弄好的TGV作。
* Q 日本的雷射設備商 / A 去日本介紹的時候他們發現我們的技術更好。
* Q 台灣檢測跟改質的，像蔚華他跟欣興合作很久作檢測 / A 我們有接觸，2月份有組台灣團去intel，今年十月份還會去一次，後段檢測時間比較久。
* Q 瓶頸 / A 全球都在開發，差在速度，前端問題比較少，時間足夠短，但後段都是用小時計，檢測設備如果檢出率達標就是看速度。
* Q 對你們最有量的設備 / A 日本就是TGV為主，台灣就是後段的設備簡報內的。
* Q 台灣的ABF會是一家還是 / A 積極度比較高的技術足夠的目前就一家。
* Q 剛剛說台積的就是CPO的專案 / A 不是。
* Q 剛剛說瓶頸是在哪個 / A 金屬化之後填孔後，檢測要看有沒有填滿、有沒有氣泡，玻璃的微裂、缺陷，所以比較難。改質那邊的話斷層AOI就可以。
* Q 電漿那邊乾濕蝕刻，玻璃那邊，有辦法用電漿解方 / A TGV雷射改質+濕製程已經定下來，你說濕製程要取代掉那是CPO的議題，現在CPO也是TGV去做(現有方案也是改質+濕蝕刻)，我們做法不一樣，就不要濕蝕刻，那邊就沒有電漿只有雷射。
* Q CPO還在驗證 / A 驗證平台26M8會好，客戶在排隊。
* Q CPO合聖跟大立光方案對鈦昇有不同嗎 / A 有看到大立光公布的內容走蠻快，合聖特定是材料面，他異質材料(混到玻璃內基材不同)對我們而言雷射可以做，都可能是我們客戶。
* Q 大立光的機會對你們比較遙遠 / A 它們已經有公告合作對象，我們的做法自己評估是比現在市場上的好。
* Q 合聖跟大立光都希望對準更精準 / A 他們做的是一樣的東西，都要解決耦合的問題，他如果做出來後面耦合就不需要，所以開發耦合的廠商前景就堪慮。
* Q 玻璃橋 / A 1.6T還是現有架構，等到3.2T玻璃橋價值就會出來，所以沒有誰取代誰的問題。
* Q 三年後會出現 / A 差不多，1.6T 2027，3.2T 2028，每個市場定位不同。
* Q 玻璃基板以後會塞光纖跟我們雷射有關嗎 / A 很難說，intel的夢想是一塊玻璃上面都已經一體成形，後面到底是不是雷射現在也沒辦法回答。
* Q TGV日本跟美國哪個比較快 / A 日本比較快因為產線規劃跟我們談得差不多，分兩部分，後段的明年上半年就要有設備，TGV他放到明年下半年。
* Q 日本客戶的戰略目標 / A 它們跟幾個美系的IC設計公司在談。
* Q 2027年下半產能夠 / A 夠，橋科的地板面積大概現在的1.6倍，製造廠房也有1.2倍，現在缺的是料還有缺工。
* Q 料會提前拉嗎 / A 提前一年比較難，因為很多設備是客製化。
* Q 今年下半到明年上半還有甚麼大支出 / A 沒有，下半年橋科開幕就開始營運。
* Q 日本客人對業績轉折的時間點 / A 都要到明年，那些都長交期lead time6個月的，他明年要今年就要給我訂單，上半年會有眉目，現在熱門的是TGV、PLP、CPO，但我們公司產品很廣，那都只有其中一塊而已，單一TGV拉起來要到27Q4，今年emib也是去年沒估到。
* Q 設備會漲價嗎 / A 會漲明年的，新機台都會把價格往上拉，我們期望今年盈餘。
* Q 缺貨的元件是比較痛點的 / A IPC，研華樺漢，一台機器可能要2~3台IPC，所以COWOS就卡很多，台達電的東西driver也缺。
* Q 機構件沒缺 / A 不是每家設備商都需要用到雷射。
* Q IPC lead time / A 從原本1.5個月幾乎double變成3個月。
* Q TGV對我們的營收貢獻 / A 美系只有出最上面的改質，很多材料上的議題，對設備營收貢獻很難定義，因為一條線他也還沒定義需要多少片，我們剛剛也提說我們一台設備抵別人30台，所以要等量產，我們有兩三台在intel那邊也不一定算一條線因為可能是mini line。
* Q ABF壓模他有找台廠嗎 / A 不清楚。
* Q intel的雷改現在會拿德廠嗎 / A 回到他要慢慢做德國也可以作，他速度大概一秒50~60，我們大概1500~2000。
* Q 會有良率問題嗎 / A 基本上都是良率OK才會比速度。
* Q 良率要求 / A 連續五片每片可能一百多萬孔都沒問題，才算良率ok。
* Q 他是一個雷射光跑1500次 / A 對。
* Q knowhow / A 雷射光路設計有突破，軟硬體要搭配。
* Q 打孔費用 / A 不會另外收。
* Q 有估乾蝕刻那邊的share嗎 / A 不管乾濕蝕刻，前面都有玻璃改質玻璃比較脆弱所以蝕刻可以吃。
* Q 乾溼蝕刻原本濕蝕刻速度比較快，但現在聽到兩邊速度差不多 / A 你說晶呈乾蝕刻，他可以做比較高深寬比，但他氣體是比較毒的，它們只能幫人家代工，他不可能每家客戶都去建那個環境，所以他要幫玻璃基板每家都做代工，他們乾蝕刻吃出來孔確實不錯，腐蝕氣體孔徑孔壁都比濕蝕刻好，濕蝕刻有速率問題。
* Q 現在晶呈訂單明確 / A 還沒聽到有誰要量產。
* Q 設備價格 / A TGV1的話底下ABF切割大概0.8(千萬台幣量級)。
* Q 跟晶呈有競爭嗎 / A 沒有，他算我們後製程。
* Q 孔徑 / A 目前都是開50~100um，主流在80~120um。
* Q 神山驗證的東西是中介層嗎 / A 不是。
* Q 下半年700*700 / A 美系，台廠FOPLP就`[[3481群創]]`，之前就交了，是他們第一條線，他們後面談一個3.5代620的規格。
* Q 一條FOPLP的價格是 / A 全部大概30E左右，5~6E是鈦昇的部分，一條線的定義好像幾千片。
* Q 日月光、力成、群創誰的積極度高 / A 一定力成，他十年前就做510*515，力成早期是跟intel談規格，上修是intel想回到FOPLP這邊作，他開的規格也是510*515這跟我們有關，力成現在擴廠是因為AMD給他單，跟intel關聯度不高。
* Q 我們會有AMD的貢獻嗎 / A 我們那條是十年前，他都去找日系的設備商，他當初就是用日系規格為主。
* Q 雷射跟電漿設備產能會分開 / A 對，目前雷射:電漿在6:4到6.5:3.5，整年度一定雷射比較高。
* Q 單價 / A 電漿單價落差大200~3000萬台幣，雷射都1000多萬台幣，改質都200萬美金。
* Q 連家科技 / A 那是我們夥伴，TGV跟PLP都是合作夥伴，不同站點。
* Q 檢測設備 / A CMP之後的，台系美系都有，美系擴的速度比較快。
* Q 515是美國客戶到時候就出到他們fab / A 他們才開始啟動，進展沒那麼快，他們有時候跳很快，面板的設備可以直接出demo給他們，但覺得不會等到27 28。
* Q 雷射跟電漿月產能 / A 最多出到40多台，改質一個月只能出幾台。
* Q 到明年 / A 會有固定人力比例，如果銷售高峰會找外面組裝人工，一年穩定20多E的產能，如果要超過就是找外面的人，有的設備商是外包但我們沒做。
* Q 去年年底營收衝高 / A 那是spacex。
* Q 26Q1也是雷射跟電漿 / A 今年應該會是26Q4 spacex擴的程度，明年東南亞還有一兩個客戶。
* Q FOPLP / A 不管在我家還是其他人看到量都不大，copos是另一件事，但那個量大後cowos量會少，copos我們雷射有在裡面。
* Q 電漿設備差距大，目前高低階占比 / A 低階早期賣LED廠，現在高階應該抓8成左右，最近出日月光OS都大概2000萬的設備。
* Q 中國營收占比 / A 今年可能跑到4成，去年一成，用在32奈米以後的。
