# 景碩 (3189)

## 🎯 投資建議與核心結論 (Summary)
* **核心論點**：
  - **NVIDIA 核心策略供應商，非短期支援商**：
    - Nvidia 已對景碩 **Consign (出資指定) 2028-2029 年新廠設備**，證實其長期策略定位。
    - 取得 Grace CPU 50-60% 市佔，下半年出貨之 Vera CPU 亦維持 50-60% 市佔，預計 **Q4 CPU 載板市佔將達到 70%**。
    - 取得 Blackwell GPU 約 10-20% 份額，目標往 **30% 以上** 份額推進（加計 Rubin GPU 供應）。
  - **認證 T+E 玻纖混壓材料，避開缺料瓶頸**：
    - 針對 Resonac T布（石英布）嚴重短缺，導入 T+E（T-glass + E-glass 各半）混壓載板並獲 Nvidia 認可，降低 T布用量並舒緩原料緊缺（目前缺料對營收影響約 10-15%）。
  - **超額漲價彈性與設備包廠分攤**：
    - 2H26 ABF 單季漲價 7-8% 僅為原料轉嫁的基本幅；若加計產能吃緊競標（類似南電模式），實際漲幅將更高，有利獲利上修。
    - 與客戶採取「設備包產能」模式，未來 2-3 年 1500 億總擴產投資中，景碩僅需出資 300 億，其餘由客戶購買折舊，降低折舊負擔。
    - BT 載板因記憶體客戶需求強勁，部分合約漲價高達 50%，稼動率拉升至 85% 帶動毛利改善。

## 📦 主要產品與營收結構 (Products)
* **ABF 載板**：營收佔比 49%-54%，預期 2027/2028 年隨擴產推升至 64%-71%。主要用於 AI 伺服器 CPU/GPU 與高階 ASIC。
* **BT 載板**：營收佔比約 31%-38%，其中一半為 Memory (記憶體) 載板。
* **隱形眼鏡 (Contact Lens)**：營收佔比 13%-18%，由子公司晶碩 (6491) 主導。

## 🤝 供應鏈關係 (Suppliers & Customers)
* **主要上游供應商**：
  * **載板材料 (CCL / 膠片)**：Resonac (日商日立化成，供應 T+E 混壓材料)、味之素 (Ajinomoto，供應 ABF 膠片)、MGC (三菱瓦斯化學，電子樹脂)。
  * **玻纖布**：台玻 (T布認證中)。
* **主要下游客戶**：
  * **直供核心客戶**：NVIDIA (Grace/Vera CPU 主要供應鏈，Blackwell GPU 載板)、AMD (General Server CPU)、GUC (源自信驊 BMC 載板需求)。
  * **早期驗證中客戶**：Google、AWS、Meta (ASIC 載板)。

## 📝 歷史筆記與會議紀要 (Notes & Memos)

### 📌 2026-06-26 實體座談會紀要 (穆顯爵處長主講)
* **[營運現況]** 5 月自結表現優於研究員原先預估，毛利率拉升至 26-27%，主要由 Nvidia 產品量產與良率提高所帶動。
* **[技術突破]** Grace CPU 採用的 T+E 混壓方案獲得 Nvidia 認可，此方案大幅降低了 T-glass 的用量限制，對公司營收釋放為關鍵 Upside。目前缺料影響營收的幅度僅 10-15%。
* **[漲價前景]** 處長指引 2H26 逐季漲價 7-8% 為反映原料上漲的基本底限，若市場產能持續吃緊，客戶競標產能的超額溢價將推升實際漲幅。
