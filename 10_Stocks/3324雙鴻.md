### 📌 [2026-11-18] 雙鴻(3324) Call memo(Jia自用)＋會後Q&A：3Q26營收97.87億元、GM 25.6%、水冷占比62%；2027 Server 90%、水冷80%、ASIC營收超過GPU、新產品(雙面水冷板/底座)占營收30-40% (來源: [[20261118_174638_text.md]]；Lucas同事Jia自用筆記)
**3Q26營運**：營收97.87億元；**GM 25.6%**(消費性電子多項專案試產)；產品組合：**Server 81%、PC 14%、VGA 4%**；**水冷比重62%**；4Q26 ASIC量產、DDR量產有利產品組合；**2027F Server 90%、其他10%；2027F水冷80%、氣冷20%**。晶片TDP目前3,000W、明後年往6,000W；加強低溫bonding、雷射焊接技術。
**Q&A(逐題完整保留)**：
1. **TDP 6,000W用什麼方案？** **MCL雙相水冷板；10KW方案用冷媒；水冷板可解到8,000W**；VC Cold Plate(用VC均熱再用Cold Plate帶走)；**鑽石銅已做出POC方案，目前看NV與ASIC都有在問，但鑽石銅有高溫衰退與可靠性問題**；**Rubin Ultra設計：QD改換成ZQD(零流阻QD)**；冷板厚度H100 0.15→VR 0.1→0.06-0.08；潔淨度80 micron往50 micron。
2. **AI降溫？** 看他們(客戶)回收的速度，目前是現金支出>流入；我們來看想辦法擴張算力；**2027資本支出已確定，2Q27-3Q27來看接下來AI發展**。
3. **2027 Server占比90%？ASIC設計？** **2027 ASIC超過GPU**；雙面水冷板也有做、A客戶有用；**雙面水冷板ASP×1.5、已在出貨**；**明年ASIC兩個客戶都用雙面水冷板(CSP:2家上下夾；NV是上面水冷板、下面底座)**提高解熱能力；**90%裡面超過一半是ASIC**；NV現在接的比去年好、ASIC從0開始有很大成長。
4. **GM？** **2027 GM比今年好很多；ASIC毛利率略高於NV**；2027是不錯的一年。
5. **2027 CDU？太空發展及技術？** 討論中；水冷首先要克服重力問題、流體不能用，可能用冷媒(低溫不會解凍)；更大散熱面積需太空產業的人完成；冷媒+CDU運作；**CDU占2027營收5-10%**；太空inner/Rack manifolds/CDU都要改；Cold Plate一定會用到、只是材料不一定是銅，焊接需更符合自動化規劃。
6. **2027 Server YoY？水冷YoY？** **2027整體營收YoY不會低於2026**。
**會後Q&A**：
* **AI放緩**：趨勢不會變、只是成長多少；基期再墊高、YOY可能收斂但方向不變。
* **資本支出**：高峰是今年明年；**2026/2027資本支出都是40-50億元**；今年不如預期是有部分需求遞延。
* **現金流**：是負的(即便一年都健康、擴充中)。
* **GM**：DIMM ASP很高、2027也是挹注；**雙面的或底座的都蠻貴、ASP都是1.5X；新產品2027年占營收30-40%(雙面+底座)**。
* **成長性**：NV氣冷轉全水冷產值增50%是既有；**軟銀也做得很積極、算力提升到極致；Apple(水果)也都在做自己的Data center**；提升算力不會停。
* **有沒有黃仁勳的差異**：他是偏執狂、逼得身邊供應鏈也變偏執狂；**兩年一代變成一年一代、供應鏈步調是以前的四倍**；沒他在確實有可能放緩。
* **鑽石銅**：很難加工、目前都是很大問題；物理極限就要換材料；液態氮澆GPU可行(立刻汽化)但超貴，所以看KW數決定材料。
* **MCL**：**下一代(Ultra)就會用、在trying中**；雙鴻也有機會；比較密的水冷板(定義TIM1.5+Plate)；**還不是Kyber架構**。
* **擴產**：**泰國三期明年底**(for Cold Plate/manifolds/CDU)。
