# 創意 (3443)

## 🎯 投資建議與核心結論 (Summary)
* **核心論點**：
  - **3nm 先進封裝 CPU 專案穩固，ASP 倍增**：
    - 針對 Marvell 搶回第三代 CPU 的市場傳言，機構證實其屬於不同產品線，不影響創意。
    - 創意仍穩拿 3nm 下一代 CPU 項目，採 dual-die 設計，ASP 預計調漲 **60-80%**，預計 2H27 開始小量出貨，2028 年協同新 XPU 爆量。
  - **US ADAS（Tesla AI5 等）為長期成長支柱**：
    - 美系 ADAS 專案（如 Tesla AI5 等）出貨能見度高，維持 2027/2028 出貨 100 萬/200 萬顆的預測，高出貨量將延續至 2028-2030 年。
  - **下半年營收加速與目標價上調**：
    - 3Q26 起受惠於 Google CPU 放量與新專案投產，營收將顯著加速。
    - 機構維持「表現優於大盤 (OUTPERFORM)」評等，目標價由 **6,000 元** 調升至 **7,500 元**（基於 40x 2H27-1H28 P/E 估值）。
  - **台積電先進封裝專屬合作**：專注與 TSMC 的 CoWoS/3D 封裝技術合作，不使用 Intel EMIB。

## 📅 重大事件與時間軸 (Schedule)

### 📌 核心重大事件 (Key Developments)
* **CLSA 目標價調升與謠言澄清**：2026-06-30 證實 3nm 先進封裝 CPU 專案穩固，Marvell 無影響，ASP 上修 60-80%，目標價調高至 7,500 元。
* **Google CPU (Axion) & TPU 機會**：Google CPU (Axion) 雖毛利低，但出貨量大，帶動 Q3/Q4 營收 QoQ 顯著成長。下一代 CPU 將採 3nm 製程且封裝尺寸更大。此外，Google 傾向收回部分功能自研，釋出的後端 (Back-end) ASIC 設計需求有機會成為創意的新動能，若有斬獲最快將在 2029 年貢獻。
* **Tesla AI5 (TK1 專案)**：Tesla 將是長期核心客戶，2026-04 已 Tape-out，預期 2027H2 開始量產，量非常大，由創意負責後段設計。預計 Tesla 將在 2028 年超越 Google CPU 成為第一大客戶。
* **微軟與 Meta 專案**：微軟第二代 CPU 預計將於 2027 年下半年量產，預估明年（2027）給予的展望會更好；Meta 則持續 Approach 新的消費性及其他專案。

### 📌 預估時間軸 (Expected Timeline)
* **2026-06-30**：CLSA/SinoPac 報告發布，調升評等目標至 7,500 元，大幅上修 27/28 年獲利。
* **2026-06-15**： KGI 訪談確認 2026 年 Google CPU、2027 年微軟二代與 Tesla AI5、2028 年 ADAS 爆量。
