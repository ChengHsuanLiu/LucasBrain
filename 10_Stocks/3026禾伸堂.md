# 禾伸堂 (3026)

## 🎯 投資建議與核心結論 (Summary)
* **核心論點**：
  - **高階 PSU/BBU 電源設計升級核心受惠者**：因應單 U PSU 提升效率與空間限制的要求，傳統塑膠薄膜電容轉向使用插卡式精密 NP0 諧振電容。5.5KW PSU 平均使用 70-100 顆。單一 AI 機櫃 (Rack) 從單相改為三相時需乘上 3 倍（約需 3,000 - 5,000 顆）。
  - **3相式與高功率設計用量倍增**：當 PSU 功率提升至 12kW、18kW 以上時，電感用量從 <100 顆提升至 >200 顆。為提升效率，18kW 以上改採三相 LC 諧振電路，使電容等元件數量達單相的三倍。
  - **⚠️ 2026-08-31 更新：MLCC漲價由AI高階料向通用料擴散，禾伸堂2027年底產量估達2025年3倍以上，2026 EPS估上修至14-15元**：詳見下方 Notes [2026-08-31] 條目。MLCC產業漲價已不再侷限AI最高階應用，開始向通用型甚至消費型應用擴散(國巨5-7月每月調漲、8月部分料號再漲逾10%)；全球主要MLCC廠年擴產僅約10-15%，2027年供需可能較2026年更緊俏，被動元件首選仍為國巨、禾伸堂。禾伸堂AI Server PSU高壓大容量MLCC今年持續增加設備(新增30-40台)，預估2027年底相關產品出貨量(以顆數計)達2025年3倍以上；3Q末將開始與客戶洽談2027年ASP，出貨量與ASP可望同步提升。6、7月自結EPS與Margin均優於分析師原先預期，原估2026 EPS約13元上修至14-15元以上。
  - **牛角型鋁電替代趨勢**：在 800V 以上的高壓設計中，電源大廠（如台達電）傾向採用牛角型鋁電解電容來替代超級電容（EDLC）以優化 PBU/BBU 效能。
  - **特化市場龍頭地位穩固**：為少數能穩定大量供應 LLC 高規格 NP0 的台系廠商。Nvidia 電源供應器中的 NP0 MLCC 禾伸堂市占率達 **50% 以上**。
  - **毛利結構性上升**：隨被動元件 AI 佔比攀升 (2025 年達 19%，2026 年預估上看 40%)，以及低毛利代理業務比重下滑，毛利率呈現質的轉變。
  - **⚠️ 2026-08-05 更新：2Q26 EPS優於預期30%，日韓廠認證延遲確保龍頭地位**：凱基投顧鄭宇宏(Benson)即時獲利公告，禾伸堂2Q26 EPS 3.87元(季增35%/年增179%)，毛利率26.2%優於凱基預期1.8ppt，主因伺服器電源升級帶動高階NP0 MLCC需求快速成長且該產品毛利率高於原估；費用率10.9%亦低於預期0.5ppt。EPS(原文另處寫3.85元)季增35%/年增178%，優於凱基預估30%，扣除業外收益季增5,000萬元(貢獻EPS約0.31元)後，本業表現仍優於預期。展望3Q26，隨伺服器電源持續升級、ASIC需求成長、新一代伺服器平台陸續推出，將推動NP0 MLCC產品往更高規格升級，帶動品組合優化，估3Q26毛利率及EPS均將季增。下一代18.3kW PSU將採三相電源架構、獨立電源櫃推出，雖公司已積極擴充產能，短期供給仍難完全滿足需求；預期客戶將加速導入日韓廠因應，惟日韓廠相同規格產品價格較高，禾伸堂在品質穩定度、產能及客戶配合經驗上仍具明顯優勢，有利進一步提升議價能力。**日韓大廠在高階NP0 MLCC仍在認證階段，最快4Q26才有望通過認證**，禾伸堂仍將維持其高階MLCC龍頭地位。重申「增加持股」，12個月目標價950元不變，目前股價僅交易於2027年EPS預估38.09元的14倍本益比，建議逢低布局。

## 📦 主要產品與營收結構 (Products)
- **高階 NP0 諧振電容 (LLC Resonant Capacitor)**：專用於 AI 伺服器電源供應器 (PSU) 及電池備援模組 (BBU) 的 LLC 諧振電路，單價達新台幣 6 - 10 元 (常規僅幾毛)。
- **各類高壓、高容值陶瓷電容 (MLCC)**：
  - **BBU/CBU 規格**：應用電壓 48V - 75V，採用 X7* 系列 1206 4.7uF 100V MLCC，單櫃使用 3000-5000 顆。
  - **機器人關節規格**：手/肩/小腿採用 48V 1000-1300 顆，中大型關節 72V 1500-1800 顆，大功率腿部關節需 4.7uF 120V。
- **自製與代理營收佔比 (2025 年)**：
  - 被動元件自製：42% (MLCC 佔此類別 80-90%)。
  - 主動元件代理：23% (代理新唐、禾瑞亞、GSI)。
  - 系統模組代理：14%。
  - 其他業務：21%。

### 📌 [2026-08-31] MLCC產業更新：庫存探底、漲價由AI高階料向通用料擴散；禾伸堂PSU高壓大容量MLCC量價齊揚 (來源: [[20260831_085212_text.md]])
**MLCC產業｜漲價範圍正在擴大**：過去漲價主要集中在AI Server高階MLCC，近期開始擴散到與AI共用的通用型MLCC；DDR、消費性電子相關料號過去仍處於去庫存，但近期跌價趨勢已開始趨緩。以國巨來看，5-7月幾乎每月都有調漲價格，8月部分料號再出現10%以上漲幅，漲價規格主要集中在0201、0402以上、X5R以上等產品。重要訊號：MLCC漲價已不再只侷限AI最高階應用，開始往較通用、甚至偏消費型應用擴散。

**2027供需可能進一步吃緊**：全球主要MLCC廠商目前擴產仍相對克制，約維持每年10-15%的產能增幅，相較AI Server、資料中心帶來的需求增長，供給增速有限，分析師預期2027年MLCC供需將比2026年更緊俏。被動元件首選仍為國巨、禾伸堂。

**禾伸堂｜AI Server PSU高壓大容量MLCC進入量價齊揚**：禾伸堂目前AI Server主要產品為PSU使用的大尺寸、高容值、高耐壓MLCC，這類產品規格與一般消費型MLCC差異大，也是禾伸堂目前最重要的AI成長來源之一。

**產能/出貨：2027年底有望達2025年的3倍以上**：今年持續增加相關設備，約新增30-40台。擴產節奏預計分階段進行——今年下半年持續擴充、農曆年後再有一波產能優化/擴充，預估2027年底以顆數計算的相關產品產出將達2025年的3倍以上。AI Server MLCC不是只有短期拉貨，而是公司正在按照中長期需求持續擴產。

**ASP：3Q末開始談2027年價格**：高耐壓、高容值產品製程難度更高，同樣尺寸下若要同時提高耐壓與容值，ASP會明顯增加，預計3Q末開始與客戶洽談價格，主要反映在2027年ASP，也就是2027年除了出貨量增加之外，還有ASP上升的可能，分析師預期2027年禾伸堂CSP相關營收占比會進一步提高。

**市場傳言：高階產能不夠、改用低壓MLCC替代？**：分析師認為機率不高，原因在於若改用較低耐壓的MLCC，就需要透過更多顆元件串聯來承受高電壓，但串聯後有效電容量下降，因此必須低耐壓→串聯顆數增加→MLCC使用量增加→占用更多PSU板上空間，而AI Server PSU本身空間就非常有限。因此對電源廠而言，較合理的方向仍是使用更高容值＋更高耐壓的MLCC，而不是大量低規MLCC堆疊，尤其未來往更高功率/高壓電源架構發展後，這個趨勢會更加明顯。不排除部分廠商短期因高階料不足，以低規產品暫時補缺口，但主要客戶應不太會採取這種方案。

**禾伸堂｜獲利有上修空間**：禾伸堂6、7月已公告自結數字，無論EPS或Margin均優於分析師原先預期，原先預估2026 EPS約13元左右，目前認為2026 EPS有機會達14-15元以上，此外高階MLCC Margin表現、匯率影響等，也都比原先模型假設更好。

**投資結論**：MLCC產業——AI高階料短缺/漲價→通用型MLCC開始跟漲→消費型產品跌價趨緩→主要廠商年擴產僅10-15%→2027供需有望進一步收緊。禾伸堂——AI Server PSU高耐壓/高容值MLCC→2027年底產量較2025年3倍以上＋3Q末啟動2027價格談判＋高階產品組合提升→2027具備量價齊揚邏輯。被動元件維持正向，首選國巨、禾伸堂；禾伸堂維持「增加持股」，且2026 EPS有機會由原估約13元上修至14-15元以上。
