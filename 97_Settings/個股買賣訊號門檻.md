# 個股買賣訊號門檻

> [!NOTE]
> 這份表格是 `generate_daily_report.py`（三、共識標的買賣提醒　四、資料庫個股買進/賣出訊號）
> 讀取的門檻參數，由 `lib/stock_signals.py` 的 `load_signal_thresholds()` 解析。
> **設定項**欄位是程式內部比對用的固定文字，請勿更動；「目前值」可自由調整，改完存檔後
> 下次執行 `generate_daily_report.py` 就會套用新門檻，不需要改程式碼。

## 買進訊號門檻

| 設定項           | 目前值 | 說明                                                    |
| :------------ | :-- | :---------------------------------------------------- |
| 五日線戰法期望值門檻(%) | 60  | 期望值需高於此值，且已站上5日線或5日線扣抵偏低，才觸發五日線戰法買進訊號。                |
| 回測月線期望值門檻(%)  | 70  | 期望值需高於此值，且現價貼近上升中的20日均線(月線)，才觸發回測月線買進訊號。              |
| 急跌季線期望值門檻(%)  | 80  | 期望值需高於此值，且現價貼近上升中的60日均線(季線)，才觸發急跌季線買進訊號（門檻最高，因屬逆勢承接）。 |
| 5日線扣抵偏低容忍度(%) | 6.0 | 5日線扣抵值需低於現價，且差距在此百分比以內，才算「偏低」（五日線戰法的另一種觸發條件）。         |
| 回測月線乖離容忍度(%)  | 2.5 | 現價與20日均線乖離在正負此百分比內，視為「貼近測試月線支撐」。                      |
| 急跌季線乖離容忍度(%)  | 3.0 | 現價與60日均線乖離在正負此百分比內，視為「貼近測試季線支撐」。                      |

## 賣出訊號門檻

| 設定項             | 目前值 | 說明                                        |
| :-------------- | :-- | :---------------------------------------- |
| 賣出減碼期望值門檻(%)    | 25  | 期望值低於此值 → 逢高減碼。                           |
| 賣出跌破5日線期望值門檻(%) | 50  | 期望值低於此值且已跌破5日線 → 提醒賣出（門檻較寬鬆，因額外要求技術面已轉弱）。 |
