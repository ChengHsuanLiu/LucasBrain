# 催化劑日曆設定

> [!NOTE]
> 這份表格是 `generate_invest_timeline.py` 讀取的顯示範圍參數。想調整報告要涵蓋的時間窗，直接改這份表格的日期即可，不需要改程式碼——腳本每次執行都會重新讀取本表。

## 顯示範圍

| 設定項  | 目前值        | 說明                                                  |
| :--- | :--------- | :-------------------------------------------------- |
| 開始日期 | 2026-07-11 | 早於此日期就已經結束的事件不顯示（尚未結束的仍會顯示，即使開始日期早於此設定）。留空則預設為執行當天。 |
| 結束日期 | 2026-12-31 | 開始日期晚於此設定的事件不顯示。                                    |

## 分桶顯示開關

| 設定項 | 目前值 | 說明 |
| :--- | :--- | :--- |
| 顯示年度事件 | Y | 設為 N 可關閉該區塊，不在報告中顯示。 |
| 顯示半年度事件 | Y | 同上。 |
| 顯示季度事件 | Y | 同上。 |
| 顯示明確時間事件 | Y | 同上。 |
| 顯示時間未定 | Y | 同上。 |
