# 財務指標篩選門檻參數表

> [!NOTE]
> 這份表格是 `scan_financial_score.py` 全市場財務指標篩選腳本讀取的門檻/配分參數，對應規則原始定義見 `[[財務指標篩選機制]]`。想調整篩選鬆緊或配分權重，直接改這份表格的數字即可，不需要改程式碼——腳本每次執行都會重新讀取本表。
>
> **指標代號**欄位是程式內部比對用的固定鍵值，請勿更動；其餘欄位（門檻值、配分、啟用）皆可自由調整。
>
> **比較基礎說明**：`YoY` = 本季 vs 去年同季；`QoQ` = 本季 vs 上一季；`單季` = 僅看當季數值本身，不比較。
>
> **運算子說明**：`>` `<` `>=` `<=` 皆為「數值欄位」與「門檻值」的比較；存貨銷售比兩項比較的是「本季比率 − 對照季比率」的差值（負值或0代表下降或持平）。

## 資料完整性處理原則

| 設定項 | 目前值 | 說明 |
| :--- | :--- | :--- |
| 史料不足處理方式 | lenient | `lenient`＝缺 YoY/QoQ 比較基準的個股，該指標配分基準也一併排除（不列入 max_possible_score），不因資料不齊被錯殺，並於報告中獨立列出「史料不足」區塊。`strict`＝缺資料直接視為未通過（0分），仍計入總配分基準。 |
| 最少所需季度數 | 5 | 需滿5季史料才能完整計算所有YoY項目 (data_complete=true)。 |

## 全市場掃描範圍設定

| 設定項 | 目前值 | 說明 |
| :--- | :--- | :--- |
| 納入市場別 | twse, tpex | 上市、上櫃。不含興櫃 (emerging)，流動性/資料品質較差。 |
| 排除產業類別 | ETF, ETN, Index, 上櫃ETF, 上櫃指數股票型基金(ETF), 受益證券, 大盤, 存託憑證, 所有證券, 指數投資證券(ETN), 金融保險, 金融業 | 金融保險業財報科目（無毛利率/存貨）與本規則不相容，未來可另建專用篩選規則。 |

## 流動性與市值篩選（殭屍股過濾）

> 這一關在抓財報三表「之前」先過濾，避免浪費 API 額度在明顯無交易意義的個股上，也讓報告不會混進一堆沒人在交易的殭屍股。

| 設定項 | 目前值 | 說明 |
| :--- | :--- | :--- |
| 啟用流動性/市值篩選 | Y | 設為 N 可關閉，回到只用類別過濾的舊行為。 |
| 最低市值 (億元) | 30 | 低於此市值視為殭屍股排除。資料來源 FinMind TaiwanStockMarketValue，取最近一個交易日。 |
| 最低日均成交金額 (萬元) | 1000 | 近N個交易日平均每日成交金額低於此門檻排除，避免單日爆量誤判為活躍股。資料來源 TaiwanStockPrice 的 Trading_money。 |
| 成交量回溯交易日數 | 5 | 上面「日均成交金額」的平均天數。 |
