# 任務工作流：生成盤後大盤日報 (Generate Daily Report)

> [!NOTE]
> 此工作流旨在每天盤後（建議晚上9點融資餘額資料更新後）產生一份整合大盤情況、族群強度、
> 大戶籌碼、個股買賣訊號的日報。四大區塊皆已實作完成。

## 📋 執行程序 (Execution Steps)

1. **產生報告前，先刷新全庫個股資料**（確保「四、資料庫個股買進/賣出訊號」引用的
   10_Stocks/*.md 頁面欄位皆為最新）：
   ```powershell
   python .agent/scripts/update_prices.py
   ```
   不帶參數即為全庫（~80+檔）批次刷新，更新每檔筆記 frontmatter 的
   `current_price`/`forward_pe`/`valuation_rating`/`tactical_score`/`tactical_action`。
   * 大盤情況（一）與族群強度（二）不需要額外刷新步驟——`generate_daily_report.py`
     本身在每次執行時就會即時向 FinMind/TWSE/TPEx/Fugle 抓取當下最新資料。
   * 主力大戶籌碼動向（三）的個股現價/目標價同樣是每次執行即時抓取；但大戶「持股
     部位」本身只能透過使用者手動提供新截圖、執行「更新大戶持股」工作流來更新，
     無法自動刷新，故此步驟只確保技術面/估值數字最新，不會拉出新的持股部位。

2. **執行自動化腳本**：
   ```powershell
   python .agent/scripts/generate_daily_report.py
   ```
   此腳本會：
   * 透過 FinMind 抓取上市加權指數(TAIEX)/上櫃指數(TPEx)的OHLC與成交量。成交量段落
     顯示前一交易日的成交金額（例如「較前日 10,046億量縮 -7.48%」），而非只顯示
     漲跌百分比。
   * 計算 5/20/60 均線(斜率/股價位置/乖離率)、5日均量線(是否站上/跌破、均量斜率上彎/
     下彎)、KD、MACD(額外標註目前K/D與DIF/DEA的相對位置為「交叉往上」或「交叉往下」，
     不限於當日實際發生交叉)，並偵測黃金/死亡交叉。上色慣例：「上彎」「漲過」「站上」
     等偏多字樣統一用紅色（沿用num-up），「下彎」「跌破」等偏空字樣統一用綠色
     （沿用num-down），適用於均線斜率/位置與5日均量線位置/斜率。均線與乖離表格的
     「均線」欄本身（5MA/20MA/60MA字樣）另外固定上色：5MA橘黃色、20MA紫色、
     60MA湖水綠，方便快速辨識是哪一條均線的數據列。
   * 透過 TWSE/TPEx 官方 Open API 加總融資餘額（上市/上櫃分開，以「億」為單位顯示）；
     上市金額取自 FinMind `TaiwanStockTotalMarginPurchaseShortSale` 的 `MarginPurchaseMoney`
     （官方無金額欄位，該資料集雖名為全市場但實測僅涵蓋上市）；上櫃因無官方金額資料集，
     改用 Fugle 熱力圖(上櫃)收盤價將個股張數換算金額後加總，**屬近似值**。並抓取 FinMind
     融資維持率。
   * 透過 FinMind 抓取三大法人現貨買賣超（外資/投信/自營商細分，以「億」為單位）與外資
     台指期未平倉。
   * 透過 Fugle 熱力圖公開API（上市IX0001／上櫃IX0043），用個股列的市值權重加權
     平均漲跌幅算出當日Top3/近1週Top5強勢產業，並列出各產業內領漲前5檔個股中
     漲幅有超過該產業平均漲跌幅者（未超過則不顯示）；若一個產業內漲幅超過平均的
     個股不足兩檔（含0或1檔），視為不具備「族群性」上漲的說服力，該產業整列不
     顯示，排名依實際顯示的產業重新從1開始編號（故有時Top3/Top5實際顯示筆數會
     少於3/5）；不限資料庫既有個股。族群漲跌幅上色但不加粗，族群內領漲個股為
     「股名粗體＋漲跌幅純黑不加粗」，各檔股票以「/」分隔。
   * 讀取 `.agent/data/whale_positions.csv`，列出各大戶當日買進/賣出重點（無前次
     快照可比較時僅標註「尚無前次快照可比較」及總持股數/市值；有前次快照可比較時
     列出新建倉/出清/加碼/減碼前3大），彙整2位以上大戶同時持有的共識標的（股票
     代碼/股名換行顯示，「持有大戶」欄合併大戶字母與人數如「A、B、C (3位)」，
     並新增「當前價格」欄），同時對每檔共識標的算出純技術面買進/賣出提醒（買進：
     五日線戰法即已站上5日線／5日線上彎／扣抵值偏低現價6%以內三者之一，或急跌至
     上升中的60日均線支撐，全數以紅字標記，每項提醒換行顯示；賣出：跌破5日線／
     5日線下彎／20日線下彎，每項提醒換行顯示，不含估值判斷）。「目標價上緣」欄以
     隔年預估EPS × 所屬概念股FPE上緣算出目標價，並依當前股價換算潛在投報率(PROI)，
     資料庫無EPS資料則顯示「-」。
   * 掃描 `10_Stocks/` 全庫個股（排除 .SH/.HK 等非台股標的），依隔年預估EPS × 所屬
     概念股FPE上緣（讀取 `97_Settings/概念股FPE合理區間.md`，同屬多概念取平均）算出目標價
     與期望值%，疊加均線/乖離率評分（表格內僅顯示簡化的「差」/「佳」並上色）、
     五日線與60日均線技術面訊號，產出兩類買進訊號（五日線戰法：期望值>60%且
     已站上5日線或扣抵值偏低現價6%以內；急跌至長線支撐：期望值>80%且現價貼近
     上升中的60日均線）與兩類賣出訊號（期望值<25%逢高減碼；期望值<50%且跌破5日線），
     兩表的「觸發原因」欄每項原因換行顯示；買進訊號並附上從個股筆記「核心論點」
     摘錄的80字以內投資簡述。
   * 全篇數字採「漲橘跌綠」上色慣例（正值/上漲用亮橘紅色，負值/下跌用綠色）。
     「一、大盤情況」結尾先產生以加權指數為基準、80分為起始基準、**藍色標題**的
     「大盤技術分析評分」（涵蓋漲跌/5MA乖離率/均線斜率與位置/KD·MACD方向與高檔
     背離/成交量趨勢與五日均量位置/融資維持率六大類條件加減分，另加一條補充規則：
     跌幅<1%且成交量縮+5分、5MA乖離率介於-1.5%~0%之間+5分[現價跌破5日線但缺口
     不到1.5%，代表只要反彈1.5%就足以站上5日線，屬於「隨時可能收復」的訊號，
     並非要求當天已實際上漲1.5%]），依總分換算級距標籤（<=40弱勢、40~70一般、
     70~80強勢、>80超級強勢）。若補充規則有任一項被觸發，緊接在評分標題底下用
     **藍色文字**逐條備註白話解讀（跌幅<1%且量縮→「尚未恐慌」；5MA乖離率
     -1.5%~0%→「若上漲1.5%就可以漲超過五日線，可觀察震盪狀況，看是否很快站回」），
     再以「加分項：
     A｜B」「扣分項：C｜D」兩行列出各觸發項目；再接**藍色標題**的「大盤情況總結」
     段落（綜合指數漲跌/三大法人/外資期貨/融資變化，加上評分與級距，給出整體偏多
     偏空的簡評）。
   * 標題排版：檔案開頭為 YAML frontmatter，接著是 `# 宇宙資本-盤後日報 {日期}`
     （不再產生 `*{日期}．投資幕僚團隊．盤後大盤日報*` 這行斜體副標，已停用），
     H1 底下不放分隔線，直接空兩行後接 `### 一、大盤情況`；「上市加權指數 (TAIEX)」
     與「上櫃指數 (TPEx)」兩個指數子標題改用 `####`（四階，小於「一、大盤情況」的
     `###` 三階）。
   * 產生 `30_Projects/Daily_Report/{YYYYMMDD}_DailyReport.md` 與對應 PDF。

3. **確認檔案生成與路徑**：
   * 確認新生成的日報位於 `30_Projects/Daily_Report/` 底下。

4. **回報執行結果**：
   * 告知使用者日報已成功生成，並提供連結與大盤情況的簡短摘要（例如：偏多/偏空訊號是否一致）。

## 🚧 開發現況

四大區塊（一、大盤情況／二、族群強度／三、大戶籌碼／四、個股買賣訊號）皆已實作完成
並驗證可產出完整報告。後續若有調整需求（例如訊號門檻微調、族群強度改抓個股層級數據），
於此文件與對應 `lib/` 模組上增修即可。

## 🔗 共用模組

* `lib/market_data.py`：大盤指數/技術指標/融資/三大法人/外資期貨的資料抓取與計算。
* `lib/sector_trend.py`：Fugle 熱力圖公開API的產業漲跌幅計算（個股市值權重加權平均）
  與族群內領漲個股排序。
* `lib/whale_tracking.py`：大戶持股時間序列存取、部位變化比對、共識標的計算。
* `lib/stock_signals.py`：個股目標價（隔年EPS×概念FPE中緣/上緣）/期望值計算，以及純
  技術面訊號（`compute_technical_signals()`：5日線站上狀態/扣抵值/60日均線支撐/
  5MA·20MA斜率，含 `ma5_up` 供「五日線上彎」買進提醒），供「三、大戶共識標的」與
  「四、個股買賣訊號」共用；`get_fpe_range_for_ticker()` 回傳的 `high` 供「目標價上緣」
  計算；`extract_investment_blurb()` 從筆記核心論點擷取買進理由摘要。
* `lib/report_pdf.py`：Markdown -> PDF 產生器，與 `generate_stock_report.py`／
  `generate_weekly_focus.py` 共用同一套設計系統（serif標題、細線分隔、色塊評等徽章）。
