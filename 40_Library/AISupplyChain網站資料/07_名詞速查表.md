# 名詞速查表

> 回索引：[[00_總覽與快速入門]]｜與 [[06_54個關鍵技術白話說]] 部分重疊，此表偏向快速查詢單一名詞的簡短定義。

- **HBM**：垂直堆疊的 DRAM 與運算晶片整合，解決 AI 工作負載的記憶體頻寬瓶頸。
- **CoWoS**：台積電的先進封裝法，把邏輯晶片與 HBM 整合在同一中介層基板上。
- **NVL72**：NVIDIA 機櫃級平台，透過 NVLink 串連 72 顆 GPU，單櫃耗電超過 100kW。
- **ABF**：味之素的專用樹脂膜，用於先進 IC 封裝載板，市占率超過九成。
- **GAA**：下一代電晶體結構，閘極四面包覆通道，取代 FinFET 用於 2nm 製程。
- **EUV**：波長 13.5nm 的極紫外光曝光技術，由 ASML 獨家供應。
- **CPO**：把光學引擎直接整合進交換器 ASIC，縮短訊號傳輸距離並降低功耗。
- **NVLink / Fusion**：NVIDIA 專有的機櫃內 Scale-Up 互連技術；Fusion 為部分開放版本。
- **UALink**：AMD 主導的開放式機櫃級 GPU 互連標準，對抗 NVLink 封閉生態系。
- **ASIC／XPU**：CSP 針對自身工作負載設計的客製化晶片（Google TPU、AWS Trainium、Meta MTIA、Microsoft Maia）。
- **OSAT**：委外封裝測試廠，負責切割、封裝與最終測試。
- **BMC**：基板管理控制器，獨立於主 CPU 提供伺服器遠端監控功能。
- **CDU**：冷卻分配單元，管理機房與機櫃冷卻液迴路間的熱交換。
- **800V HVDC**：高壓直流供電架構，可降低銅材用量與傳輸損耗達 45% 以上。
- **DSP（光模組語境）**：光收發模組內建的數位訊號處理器，用來補償傳輸造成的訊號失真。
- **RPO**：未來營收保證，反映訂單積壓量與營收能見度（如 Microsoft 雲端 RPO 約 6,270 億美元）。
- **CUDA**：NVIDIA 的開發者生態系，號稱擁有超過 6 億使用者，是主要的軟體黏著機制。
- **玻璃基板**：以玻璃取代樹脂的下一代 IC 封裝載板，熱膨脹係數匹配更佳，材料利用率可達九成以上。
- **MLCC**：積層陶瓷電容，提供電壓平滑與濾波；AI 伺服器對高容值 X6S 等級的需求供不應求。
- **VRM**：電壓調節模組，把電源轉換工作分散到並聯相位，應對 GPU 瞬態電流突波。
- **PMIC**：電源管理晶片，整合電壓轉換、時序控制與遠端監測功能。
- **SiC／GaN**：寬能隙半導體材料，SiC 適合高壓大功率轉換，GaN 擅長高頻降壓。
- **RV 減速機**：偏心齒輪機構，提供高扭矩、耐負載的減速能力，用於機器人主關節（Nabtesco 為主要供應商）。
- **諧波減速機**：柔性齒輪機構，適合體積小、精密度高的減速需求，用於機器人次要關節（Harmonic Drive 為主要供應商）。
- **PRS（行星滾柱螺桿）**：滾動元件式線性傳動機構，功率密度優異，適合人形機器人腿部致動器。
- **VLA 模型**：視覺-語言-動作統一神經網路，讓機器人能跨場景泛化操作能力。
- **Physical AI**：NVIDIA 提出的框架，把人形機器人、自駕車與移動式機械手臂定位為 AI 應用的核心場域。
- **CW 雷射**：連續波外部光源，用於 CPO／矽光子架構，降低模組整體功耗。
- **FAU**：光纖陣列單元，在 CPO 系統中提供多光纖精密對位與晶片波導耦合功能。
