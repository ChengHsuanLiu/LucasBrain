# 📐 31_Models — 個股損益推估模型

驅動因子式（driver-based）的月度／季度損益表推估系統，產出可直接用於交易的
**滾動 12 個月 forward EPS 與 forward P/E**。

---

## 一、為什麼是這個設計

台股本地研究員本來就在做月度模型（因為每月 10 日強制公告月營收，他們追「月營收達成率」）。
所以本系統的差異**不在頻率，在紀律**：

| 項目 | 一般賣方 Excel 模型 | 本系統 |
| :--- | :--- | :--- |
| 參數來源 | hardcode 在儲存格，無人稽核 | 每個參數帶 `source` + `confidence`，自動列出弱點 |
| 基期校準 | 通常沒做 | 強制檢查模型能否重現已公布季度 |
| 過擬合防護 | 無 | 識別性檢查 + Layer1/Layer2 交叉驗證 |
| 輸出 | 點估計 + 目標價 | 三情境 + 機率加權 + 可量化失效條件 |
| 錯了怎麼辦 | 安靜 re-base | `actuals` 累積，每季重跑即自動打臉 |

參考本庫既有的兩份範本：**6213聯茂 v25/v44 三軸模型**（方法論來源）與
**1709和益 v1→v2 回顧迴圈**（承認預測失敗的機制）。

---

## 二、核心原則：兩層模型

### Layer 1（骨架，必填，8 類參數以內）

```
營收   = 產能 × 稼動率 × 混合ASP        （或 成長率法 / 直接給定）
毛利   = 營收 × 毛利率
營益   = 毛利 − 營收 × 費用率
EPS    = (營益 + 業外) × (1 − 稅率) × 母公司比 ÷ 股數
月度值 = 季度值 × month_weights
```

**這層就能給你 80% 的答案。** 聯茂 v45 的 Layer 1 只用 8 類參數，
2026 年 EPS 算出 18.49 元，對比內部 40 參數的 v44 模型 19.88 元，差距僅 7%。

### Layer 2（細節，選填）

產品組合拆解：`營收 = 產出量 × Σ(級距量佔比 × 價格指數) × 基準價`

**開啟條件：你握有級距別的一手資料。**
沒有一手資料就開 Layer 2，只是把「毛利率一個猜測」拆成「五個級距各自的猜測」，
出錯的地方變多而非變少（聯茂 v18 的 `α=0.90` 就是這樣來的）。

> **Layer 2 的角色是驗證 Layer 1，不是取代它。**
> 兩層差距 > 20% 時，預設判定為 Layer 2 過擬合，而非 Layer 2 較精確。

## 三、建模前先診斷（不要憑感覺選結構）

```bash
python .agent/scripts/diagnose_model.py 1303
```

核心原則只有一條：

> **模型結構要對準「變異數最大的地方」，其餘保持簡單。**

把細節花在低變異的環節（例如替一家獲利九成來自轉投資的公司細拆本業產品組合），
不會讓模型更準，只會讓它更難維護、更容易過擬合。

診斷腳本用近 9 季財報把 Δ稅前淨利**精確**分解為五項（加總恆等，非近似）：

| 效應 | 公式 | 若它主導代表 |
| :--- | :--- | :--- |
| 營收 | Δ營收 × 前期營益率 | 量／產能驅動 → 原型 A |
| 毛利率 | 前期營收 × Δ毛利率 | 價格／利潤率驅動 → 情境軸放毛利率 |
| 費用率 | −前期營收 × Δ費用率 | 需拆固定＋變動費用 |
| 業外 | Δ業外（含權益法） | 轉投資主導 → 必須開 `equity_income` |
| 交乘 | Δ營收 × Δ營益率 | 量價同時劇烈變動 |

三檔實測（腳本自行判定，與人工結論一致）：

| 個股 | 最大變異來源 | 業外依賴度 | 判定 |
| :--- | :--- | ---: | :--- |
| 6213聯茂 | 毛利率 45% | 10% | 情境軸放毛利率 |
| 6805富世達 | 營收 33% ≈ 毛利率 27% | 13% | 情境軸需同時涵蓋兩者 |
| 1303南亞 | **業外 71%** | **92%** | 必須 look-through，情境軸放被投資公司 |

## 四、三種原型

| 原型 | 適用產業 | 驅動軸 | `method` | 範例 |
| :--- | :--- | :--- | :--- | :--- |
| **A 產能驅動** | CCL／PCB／載板／被動／散熱／代工 | 產能 × 稼動率 × 混合ASP | `capacity` | `6213聯茂` |
| **B 專案驅動** | 連接器／設備／探針卡／IC設計 | 分部門營收（各自毛利率） | `segments` | `6805富世達` |
| **C 價差驅動** | 化工／原材料 | 售價(現貨,即時) − 成本(長約,落後L期) | `growth` + 自訂毛利率序列 | — |

### 權益法投資收益（控股／轉投資型公司）

若公司獲利有相當比重來自轉投資（台塑集團、控股公司），**不要把它塞進「業外」當常數**。
用 `layer1.equity_income` 逐季驅動：

```yaml
equity_income:
  taxable: false            # 國內轉投資權益法收益不再課稅
  investees:
    南亞科技:
      ticker: "2408"
      stake: {value: 0.322, source: 由實際認列數反解, confidence: 反解}
      net_income: {2026Q2: {value: 454.5, source: 2408財報, confidence: 硬}}
```

持股比例可由「實際認列金額 ÷ 被投資公司同期淨利」反解。引擎會計算
**業外依賴度**（非本業貢獻佔稅後淨利比重）並在報告頂端警示。

> 依賴度超過 50% 時，這已經不是一個「本業模型」——
> 把被投資公司的獲利假設做對，價值遠高於把本業拆得更細。
> 南亞 1303 就是這種案例（業外佔淨利 63%，本業只佔約 1/3）。

`segments` 法下，公司層級毛利率的取用順序是：
**該季有明確指定 → 用指定值**（通常是已公布財報的實績，確保基期校準過得了）；
**否則 → 由各部門營收加權推導**。這讓「歷史季度鎖實績、未來季度跟著組合變化跑」自動成立。

## 五、參數信心分級

| 等級 | 定義 | 例 |
| :--- | :--- | :--- |
| `硬` | 公司公開或親口給的數字 | 財報實績、法說產能公告、私訪逐字 |
| `軟` | 公司給區間或方向，我們取其中一點 | 「3Q毛利率25-30%」→ 取 28% |
| `反解` | 由已公布財報回推的隱含值 | 26Q2 稼動率 74.44%、有效稅率 31.9% |
| `推估` | **沒有一手來源，我們自己填的** | 2027 年毛利率 32% |

`推估` 參數會被稽核區塊單獨列表——**那張表就是下次法說會/私訪的提問清單**。

## 八、維護迴圈

```
每月 10 日  月營收公告 → 與 output_monthly.csv 對帳
            └→ 連兩月偏離 >10% → 檢討稼動率/ASP 假設

每季財報    → 把實績寫進 params 的 actuals 區塊 → 重跑
            └→ 基期校準若失敗，先修參數再談前瞻數字
            └→ 反解更新（稼動率、有效稅率、級距毛利率）
            └→ 版本升版，舊版 params 保留供對照
```

## 九、使用時的紀律（從聯茂/和益的教訓萃取）

1. **改版後 EPS 上修 >20% 必須紅隊覆核。**
   聯茂 v20→v22 期間 2027 EPS 一度衝到 78.56／80.95 元才修回 51.99，
   全都是模型自己算出來的、每一版看起來都合理。

2. **偏離法人共識 >30% 時，必須能說出共識隱含了什麼假設。**
   說不出來就是模型在追價。報告會自動標 🚩。

3. **不要每個參數都做情境。**
   情境的分歧點應集中在方差最大的變數（通常是毛利率）。
   和益紅隊的結論：毛利率單一變數的方差大於其他所有變數方差的總和。

4. **月度值只用來抓趨勢偏離，不要當單月預測。**
   單月出貨時點噪音常達 ±10%，模型跑季度、再依權重拆到月才是正確用法。

5. **這套東西的價值上限由私訪品質決定，不是由參數精緻度決定。**
   要投資時間，優先順序是「多做幾次高品質私訪」＞「把參數從 30 個做到 60 個」。

6. **建議只做 5-8 檔核心持股。** 其餘用法人共識即可。
